## 第一节 分布式假设

### 一、语境决定意义

**分布式假设（Distributional Hypothesis）**是分布式语义学的理论基石：

> "You shall know a word by the company it keeps." — J.R. Firth (1957)

**核心主张**：词语的意义由其在语料库中的分布模式决定。出现在相似语境中的词语具有相似的意义。

**形式化表述**：
```
sim(w₁, w₂) ∝ sim(context(w₁), context(w₂))

词语相似度与语境相似度成正比
```

### 二、语境的定义

**语境**可以有多种操作化定义：

| 语境类型 | 定义 | 示例 |
|---------|------|------|
| **词袋语境** | 同一文档中的词 | 文档级共现 |
| **窗口语境** | 固定窗口内的词 | ±5词窗口 |
| **句法语境** | 句法关系连接的词 | 依存关系 |
| **篇章语境** | 篇章结构中的邻居 | 同一段落 |

### 三、分布式语义的哲学基础

分布式假设与**后期维特根斯坦**的语言哲学呼应：

> "词语的意义就是它在语言中的使用。"

这一观点反对意义的心智主义解释，主张从语言使用中学习意义。

## 第二节 向量空间模型

### 一、词-文档矩阵

**向量空间模型（Vector Space Model, VSM）**将词语表示为高维空间中的向量。

**词-文档矩阵**：
```
        Doc1  Doc2  Doc3  ...
word1 [  3     0     1   ...]
word2 [  0     2     0   ...]
word3 [  1     1     4   ...]
...
```

**TF-IDF加权**：
```
tfidf(t, d) = tf(t, d) × log(N / df(t))

其中：
tf(t, d) = 词t在文档d中的频率
df(t) = 包含词t的文档数
N = 总文档数
```

### 二、词-词共现矩阵

**词-词矩阵**直接编码词语间的共现关系：

```
        word1  word2  word3  ...
word1 [   0     12     3   ...]
word2 [  12      0     8   ...]
word3 [   3      8     0   ...]
...
```

**PMI加权**：
```
PMI(w₁, w₂) = log(P(w₁, w₂) / (P(w₁) × P(w₂)))

正PMI (PPMI) = max(0, PMI)
```

### 三、降维技术

**SVD（奇异值分解）**用于降维和去噪：

```
M = U Σ Vᵀ

保留前k个奇异值：
M̂ = Uₖ Σₖ Vₖᵀ
```

**LSA/LSI**：基于SVD的潜在语义分析

## 第三节 神经词嵌入

### 一、Word2Vec

Mikolov等人（2013）的**Word2Vec**开创了神经词嵌入时代。

**CBOW（Continuous Bag of Words）**：
```
输入：语境词 [w₋₂, w₋₁, w₊₁, w₊₂]
输出：中心词 wₜ
目标：最大化 P(wₜ | context)
```

**Skip-gram**：
```
输入：中心词 wₜ
输出：语境词 [w₋₂, w₋₁, w₊₁, w₊₂]
目标：最大化 P(context | wₜ)
```

### 二、GloVe

Pennington等人（2014）的**GloVe**结合了全局统计和局部语境。

**目标函数**：
```
J = Σᵢⱼ f(Xᵢⱼ)(wᵢᵀw̃ⱼ + bᵢ + b̃ⱼ - log Xᵢⱼ)²

其中 Xᵢⱼ 是共现次数
```

### 三、FastText

Bojanowski等人（2017）的**FastText**引入子词信息：

```
词向量 = Σ 子词向量

"where" → <wh, whe, her, ere, re>
```

**优势**：处理未登录词，捕捉形态信息

### 二、NV-Embed-v2的核心创新

**NV-Embed-v2**（NVIDIA, arXiv:2405.17428）以**72.31分**领先MTEB：

1. **潜在注意力层**：使用512个潜在向量和8个注意力头替代均值池化
2. **两阶段对比指令微调**：先检索数据集训练，再混合非检索数据集
3. **移除因果注意力掩码**：启用双向注意力
4. **正例感知硬负例挖掘**：提升难负例质量

### 三、BGE-M3的三重M范式

**BGE-M3**（BAAI, arXiv:2402.03216, ACL Findings 2024）：

| M | 含义 | 功能 |
|---|------|------|
| **Multi-Functionality** | 多功能 | 稠密、稀疏、多向量（ColBERT风格） |
| **Multi-Linguality** | 多语言 | 100+语言 |
| **Multi-Granularity** | 多粒度 | 最长8192 tokens |

**混合检索公式**：
```
s_rank = w1·s_dense + w2·s_lex + w3·s_mul
```

## 第五节 语境化嵌入与长文档处理

### 一、从静态到动态

传统词嵌入为每个词分配**固定向量**，无法处理**多义性**。

```
"bank"的不同意义：
- "river bank" — 河岸
- "bank account" — 银行

静态嵌入：相同向量
语境化嵌入：不同向量
```

### 二、Late Chunking技术

**Late Chunking**（Jina AI, arXiv:2409.04701）是2024年最重要的长文档嵌入创新：

**传统方法问题**：
```
传统分块：文档 → 分块 → 独立编码每个块
问题：每个块丢失文档级语境
```

**Late Chunking方法**：
```
1. 先用长上下文模型嵌入整个文档
2. 然后通过均值池化生成每个分块的嵌入
优势：保留跨分块的上下文信息
```

**性能**：在NFCorpus、LongEmbed基准上显著优于朴素分块

### 三、Matryoshka表示学习

**俄罗斯套娃嵌入（MRL）**（Kusupati等人, NeurIPS 2022, arXiv:2205.13147）：

**核心思想**：允许在多个截断维度上使用嵌入（如1024→512→256→128→64）

**效果**：
- 最高**14倍**的嵌入压缩
- **14倍**的实际检索加速

**采用MRL的主要模型**：
- Nomic Embed v1.5（64-768维）
- Jina v3（32-1024维）
- Voyage系列（256-2048维）
- OpenAI text-embedding-3系列

**2D Matryoshka**（arXiv:2402.14776）：同时支持可变层数和维度

### 二、混合检索架构

```python
def hybrid_retrieval(query, corpus):
    """稀疏-稠密混合检索"""
    
    # 稠密检索
    dense_scores = dense_retriever.score(query, corpus)
    
    # 稀疏检索（SPLADE/BM25）
    sparse_scores = sparse_retriever.score(query, corpus)
    
    # 多向量检索（ColBERT风格）
    multi_scores = multi_vector_retriever.score(query, corpus)
    
    # BGE-M3混合公式
    final_scores = w1 * dense_scores + w2 * sparse_scores + w3 * multi_scores
    
    return rank_by_scores(corpus, final_scores)
```

### 三、Late Chunking实现

```python
def late_chunking_embedding(document, encoder, chunk_size=512):
    """Late Chunking保留语境"""
    
    # 1. 整体编码（使用长上下文模型）
    full_embeddings = encoder.encode_full(document)  # [seq_len, dim]
    
    # 2. 确定块边界
    chunk_boundaries = get_chunk_boundaries(document, chunk_size)
    
    # 3. 对每个块提取嵌入（均值池化）
    chunk_embeddings = []
    for start, end in chunk_boundaries:
        chunk_emb = full_embeddings[start:end].mean(dim=0)
        chunk_embeddings.append(chunk_emb)
    
    # 每个块保留了全文语境
    return chunk_embeddings
```
