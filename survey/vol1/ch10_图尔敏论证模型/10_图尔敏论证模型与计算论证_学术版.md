## 第一节 图尔敏论证模型的理论基础

### 一、图尔敏模型的哲学背景

Stephen Toulmin在其1958年著作《The Uses of Argument》中提出了影响深远的论证模型，挑战了传统形式逻辑在日常推理分析中的适用性。Toulmin认为，亚里士多德式的演绎三段论虽然在数学证明中有效，但无法捕捉人类日常论证的实际结构和复杂性。

**核心洞见**：论证不是抽象的逻辑演算，而是**社会实践**——论证的有效性取决于其在特定**论证场域**（field of argument）中的恰当性。法律论证、科学论证和日常对话中的论证遵循不同的规范和标准。

### 二、图尔敏模型的六要素

**声明（Claim）**
论证的核心主张，即论证者希望听众接受的结论。

> 例：人工智能将深刻改变劳动力市场。

**数据/理据（Data/Grounds）**
支持声明的事实、证据或前提。

> 例：自动化技术已经替代了制造业中30%的重复性工作岗位。

**授权（Warrant）**
连接数据与声明的推理规则或原则，解释为什么数据能够支持声明。

> 例：技术变革历史上总是导致劳动力结构的重大调整。

**支援（Backing）**
为授权提供进一步支持的信息，增强授权的可信度。

> 例：工业革命和信息革命都引发了大规模的职业转型。

**限定词（Qualifier）**
表达声明确定性程度的词语，如"可能"、"很可能"、"必然"。

> 例：**很可能**人工智能将深刻改变劳动力市场。

**反驳/例外（Rebuttal）**
指出声明不成立的条件或例外情况。

> 例：除非政府采取有效的再培训政策和社会保障措施。

### 三、图尔敏模型的形式表示

```
          Qualifier
             ↓
Data ──→ [Warrant] ──→ Claim
             ↑              ↑
          Backing       Rebuttal
```

这一结构可形式化为：

```
CLAIM(c) ← DATA(d) ∧ WARRANT(w) ∧ ¬REBUTTAL(r)
           with CONFIDENCE(q)
           where BACKING(b) supports WARRANT(w)
```

## 第二节 从图尔敏到计算论证：理论演进

### 一、论证图谱的发展

图尔敏模型为**论证图谱**（Argument Maps）的发展奠定了基础。论证图谱将论证结构可视化，节点代表命题（声明、前提、证据），边代表支持或攻击关系。

**抽象论证框架（Abstract Argumentation Framework, AAF）**由Dung（1995）提出，将论证抽象为节点集合和攻击关系：

```
AF = (Args, Attacks)
```

其中Args是论证集合，Attacks ⊆ Args × Args是攻击关系。

### 二、从结构到语义：论证语义学

AAF引入了多种**论证语义**来确定哪些论证是"可接受的"：

- **完全扩展（Complete Extension）**：包含所有被辩护的论证
- **基础扩展（Grounded Extension）**：最小的完全扩展
- **优选扩展（Preferred Extension）**：最大的可辩护集合
- **稳定扩展（Stable Extension）**：攻击所有外部论证的可辩护集合

### 三、计算论证的任务分类

现代计算论证研究包括以下核心任务：

| 任务 | 定义 | 图尔敏对应 |
|------|------|-----------|
| **声明检测** | 识别文本中的论证主张 | Claim |
| **证据检测** | 识别支持声明的证据 | Data/Grounds |
| **关系分类** | 判断论证单元间的支持/攻击关系 | Warrant方向 |
| **立场检测** | 判断论证对特定目标的态度 | Claim极性 |
| **论证质量评估** | 评估论证的说服力和充分性 | 整体结构完整性 |
| **论证摘要** | 生成论证的简洁表示 | 核心要素提取 |

## 第三节 LLM时代论证挖掘的范式革命

### 一、综述：从监督到提示驱动

Li H等人（arXiv:2506.16383, 2025）发表的综合综述系统记录了计算论证领域的根本性转型。传统的论证挖掘依赖：
- 任务特定的监督分类器
- 大规模人工标注数据
- 特征工程和序列标注模型

**LLM时代的新范式**特征包括：
- **提示驱动**：通过精心设计的提示引导LLM执行论证任务
- **检索增强**：结合外部知识库增强论证推理
- **推理导向**：利用思维链等技术进行多步论证分析

**综述覆盖范围**：
- 时间跨度：2015-2025年约250篇研究论文
- 六大任务类型：声明检测、证据检测、关系预测、立场分类、论证质量评估、论证摘要
- 四大核心挑战：长上下文推理、多模态/多语言鲁棒性、可解释性、标注瓶颈

### 二、LLM论证能力基准研究

Chen等人（ACL 2024, DOI: 10.18653/v1/2024.acl-long.126）提供了首个系统性基准研究，在**14个数据集**上评估ChatGPT、Flan和LLaMA2的零样本和少样本性能。

**核心发现**：

| 模型 | 任务 | 零样本准确率 |
|------|------|-------------|
| Flan-UL2 | IAM Claims | **83.80%** |
| ChatGPT | 立场检测 | 72.3% |
| LLaMA2 | 证据检测 | 68.5% |

**关键结论**：提示方法可匹配传统监督方法，无需大规模标注数据。

**GitHub资源**：https://github.com/DAMO-NLP-SG/LLM-argumentation

### 三、思维链推理在论证任务中的突破

**Chain-of-Stance方法**（Ma等, arXiv:2408.04649, 2024）将立场检测分解为**六步序列推理**：

1. **上下文理解**：分析文本背景和主题
2. **主旨解释**：识别核心论点
3. **证据分析**：评估支持材料
4. **立场推断**：初步判断立场方向
5. **一致性检查**：验证推理的内部一致性
6. **最终决策**：输出立场标签和置信度

**效果**：在SemEval 2016数据集上零样本和少样本设置均超越SOTA。

**LOGIC框架**（Lee等, PeerJ Computer Science 10:e2585, 2024）通过思维链提示将LLM推理能力蒸馏到小模型，实现论证推理能力的高效迁移。

## 第四节 论证图构建与关系分类

### 一、LLM论证关系分类

Gorur等人（arXiv:2402.11243, 2024）评估了LLM在论证关系分类任务上的表现，发现**Llama-2 70B和Mixtral 8x7B在4样本启动下显著超越RoBERTa基线**，无需微调即可实现攻击/支持关系的有效分类。

### 二、DISARM方法

**DISARM**（EMNLP 2024, DOI: 10.18653/v1/2024.emnlp-main.1054）通过**多任务学习**结合话语标记检测推进SOTA。核心思路是：话语标记（如"however"、"therefore"、"because"）是论证关系的显式信号，联合学习可以互相增强。

### 三、可解释论证验证

**ArgLLMs**（arXiv:2405.02079）使用**量化双极论证框架（QBAFs）**实现可解释的声明验证。QBAFs为每个论证分配数值强度，通过传播计算最终接受度，提供透明的推理路径。

## 第五节 RAG论证增强系统

### 一、RAGAR：检索增强的论证推理

**RAGAR系统**（FEVER @ EMNLP 2024, DOI: 10.18653/v1/2024.fever-1.29）引入了两种创新的RAG推理技术：

**Chain of RAG（CoRAG）**：
- 将事实核查分解为一系列子问题
- 每个子问题触发独立检索
- 逐步累积证据直至得出结论

**Tree of RAG（ToRAG）**：
- 构建证据的树状结构
- 支持论证的分支探索
- 允许回溯和路径比较

**效果**：在多模态事实核查任务上达到**0.85加权F1**。

### 二、COVID-19 RAG事实核查

JMIR 27:e66098（2025）报告了整合约130,000篇同行评审论文与GPT-4的COVID-19事实核查系统，比较了四种RAG策略：

| 策略 | 特点 | 幻觉率 |
|------|------|--------|
| 朴素RAG | 基础检索+生成 | 高 |
| LOTR-RAG | 长文本检索优化 | 中 |
| 纠正性RAG (CRAG) | 检索结果验证 | **低** |
| 自RAG (SRAG) | 自我反思机制 | **低** |

**关键发现**：CRAG和SRAG显著减少幻觉同时维持准确率。

### 三、OpenDebateEvidence数据集

**OpenDebateEvidence**（Roush等, NeurIPS 2024, arXiv:2406.14657）是目前最大规模的论证挖掘数据集：

- **规模**：350万文档
- **来源**：竞技辩论档案
- **任务**：论证检测、论证摘要、证据检索
- **HuggingFace**：huggingface.co/datasets/Yusuf5/OpenCaselist

## 第六节 图尔敏模型在RAG中的应用

### 一、声明-证据结构化检索

RAG系统可以利用图尔敏模型组织检索结果：

```
查询: "人工智能是否会导致失业？"

检索结果结构化:
┌─────────────────────────────────────────────┐
│ CLAIM: AI将导致某些职业的消失              │
│ DATA: McKinsey报告显示30%工作可自动化      │
│ WARRANT: 自动化历史上替代了重复性工作      │
│ BACKING: 工业革命期间纺织工人的案例        │
│ QUALIFIER: 在未来10-20年内很可能           │
│ REBUTTAL: 除非出现新的工作类型             │
└─────────────────────────────────────────────┘
```

### 二、论证质量感知排序

检索排序可以融入论证质量维度：

1. **证据充分性**：Data是否足以支持Claim？
2. **授权明确性**：Warrant是否被显式表达？
3. **反驳完整性**：是否考虑了主要反对意见？
4. **声明具体性**：Claim是否足够具体可检验？

### 三、反驳生成与平衡呈现

RAG系统可以通过检索对立证据生成反驳：
