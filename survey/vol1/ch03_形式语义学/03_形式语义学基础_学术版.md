## 第一节 形式语义学的哲学渊源

### 一、从自然语言到形式语言

**形式语义学（Formal Semantics）**的核心目标是用精确的数学工具描述自然语言的意义。这一传统可追溯到Frege、Russell和Tarski的逻辑语义学工作。

**核心假设**：
- 自然语言的意义可以形式化表示
- 复杂表达式的意义由其组成部分的意义组合而成
- 意义与世界之间存在系统性对应关系

### 二、组合性原则

**组合性原则（Principle of Compositionality）**是形式语义学的基石：

> 复杂表达式的意义是其组成部分意义及其组合方式的函数。

**形式表述**：
```
⟦α β⟧ = f(⟦α⟧, ⟦β⟧)

其中：
⟦·⟧ 表示语义解释函数
α β 是复杂表达式
f 是语义组合函数
```

### 三、真值条件语义学

**真值条件语义学（Truth-Conditional Semantics）**将句子的意义等同于其真值条件：

> 理解一个句子的意义，就是知道在什么条件下这个句子为真。

**示例**：
```
句子："雪是白的"
真值条件：当且仅当雪是白的，该句子为真
形式化：⟦雪是白的⟧ = 1 iff 雪是白的
```

## 第二节 蒙太古语法

### 一、蒙太古的核心贡献

Richard Montague在1970年代提出的**蒙太古语法（Montague Grammar）**证明了自然语言可以像形式语言一样获得精确的语义解释。

**核心论点**：
> "我认为自然语言与逻辑学家的形式语言之间不存在重要的理论差异。"

### 二、类型论基础

蒙太古语法基于**类型论（Type Theory）**构建语义系统。

**基本类型**：
- **e**（entity）：个体类型
- **t**（truth value）：真值类型

**复合类型**：
- **⟨e, t⟩**：从个体到真值的函数（性质）
- **⟨e, ⟨e, t⟩⟩**：二元关系
- **⟨⟨e, t⟩, t⟩**：广义量词

**类型对应**：

| 语法范畴 | 语义类型 | 示例 |
|---------|---------|------|
| 专有名词 | e | "北京" |
| 不及物动词 | ⟨e, t⟩ | "跑" |
| 及物动词 | ⟨e, ⟨e, t⟩⟩ | "爱" |
| 量词短语 | ⟨⟨e, t⟩, t⟩ | "每个学生" |

### 三、Lambda演算

**Lambda演算（Lambda Calculus）**是蒙太古语法的核心工具：

**Lambda抽象**：
```
λx.P(x) 表示满足性质P的个体集合

示例：
λx.student(x) = 学生集合
λx.λy.love(x,y) = 爱关系
```

**函数应用**：
```
(λx.P(x))(a) = P(a)

示例：
(λx.student(x))(john) = student(john)
```

**现代实现——ccg2lambda系统**：
- GitHub：https://github.com/mynlp/ccg2lambda
- 从CCG推导树生成类型化Lambda演算表示
- 支持多语言语义解析

## 第三节 组合性原则的神经网络实现

### 一、2024年大规模调查

McCurdy等人（EMNLP 2024, DOI:10.18653/v1/2024.emnlp-main.524）对**79名研究者**进行问卷调查：

| 问题 | 结果 |
|------|------|
| 当前模型是否实现组合行为？ | **81%认为未实现** |
| "规模即解决方案"？ | **81%反对** |
| 是否需要模型内部结构性干预？ | **73%认为需要** |

**核心结论**：研究社区普遍认为当前LLM未能真正实现组合性。

### 二、两条融合路径

Russin等人的综述《From Frege to ChatGPT》（arXiv:2405.15164）提出两条实现路径：

**路径1：架构归纳偏置**
- 张量积表示（Tensor Product Representations, TPR）
- 在神经网络架构中显式引入组合结构
- 软TPR（NeurIPS 2024）：DCI解耦度量提升**29-74%**

**路径2：元学习**
- 将LLM预训练理解为隐式元学习过程
- 通过海量数据学习组合模式
- Nature Communications 2024证实LLM可从结构化输入受益

### 三、组合函数网络

**组合函数网络（Compositional Function Networks, CFNs）**（arXiv:2507.21004）是2025年的新突破：

**核心创新**：通过组合基本数学函数构建网络

**性能**：
- CIFAR-10准确率：**96.24%**
- 内置可解释性
- 每个节点对应可理解的数学操作

## 第四节 动态语义学

### 一、从静态到动态

传统真值条件语义学是**静态的**——将句子映射到真值。**动态语义学（Dynamic Semantics）**将句子视为**语境变换函数**。

**核心转变**：
```
静态语义：⟦S⟧ : W → {0, 1}
动态语义：⟦S⟧ : C → C
         （语境到语境的函数）
```

### 二、话语表示理论

**话语表示理论（Discourse Representation Theory, DRT）**由Hans Kamp提出。

**话语表示结构（DRS）**：
```
句子："一个农夫走进来。他很疲惫。"

DRS:
┌─────────────┐
│ x           │  ← 话语指称
├─────────────┤
│ farmer(x)   │
│ walked-in(x)│  ← 条件
│ tired(x)    │
└─────────────┘
```

**回指解析**：代词"他"在DRS中绑定到先行引入的话语指称x。

### 三、文件变换语义学

Heim的**文件变换语义学（File Change Semantics）**将语境建模为"文件卡片"集合，每张卡片记录一个话语实体的信息。

## 第五节 事件语义学

### 一、戴维森的事件论元

Donald Davidson提出**事件语义学（Event Semantics）**，将事件作为本体论实体引入语义分析。

**传统分析**：
```
John kissed Mary.
kiss(john, mary)
```

**事件语义分析**：
```
John kissed Mary.
∃e[kiss(e) ∧ agent(e, john) ∧ patient(e, mary)]
```

### 二、2024年事件语义学进展

**Narrative-of-Thought**（EMNLP Findings 2024, DOI:10.18653/v1/2024.findings-emnlp.963）：
- 将事件转换为**Python类**的提示技术
- Schema-11基准上达到**最高F1**
- 实现事件的结构化表示

**Temporal Cognitive Tree**（EMNLP Findings 2024, DOI:10.18653/v1/2024.findings-emnlp.47）：
- 模拟人类逻辑推理的层次模型
- 在TB-Dense和MATRES上**超越现有方法**
- 支持复杂时间关系推理

**ExpTime数据集**（ACM Web Conference 2024）：
- 首个可解释时间推理任务
- **26,000样本**
- 提出TimeLLaMA模型系列

## 第六节 可能世界语义学与模态推理

### 一、模态逻辑与可能世界

**可能世界语义学（Possible World Semantics）**由Saul Kripke发展，用于处理模态表达式（必然、可能）和内涵语境。

**核心概念**：
- **可能世界**：事物可能存在的方式
- **可及关系**：世界之间的可达性
- **内涵**：从可能世界到外延的函数

### 二、内涵与外延

**外延（Extension）**：表达式在特定世界中的指称
**内涵（Intension）**：从可能世界到外延的函数

```
外延：⟦晨星⟧ᵂ = 金星
内涵：⟦晨星⟧ = λw.⟦晨星⟧ᵂ
```

### 三、LLM模态推理能力评估

Holliday等人（EMNLP 2024, DOI:10.18653/v1/2024.emnlp-main.222）测试了**12+个LLM**在**30+条件句和认知模态推理模式**上的表现。

**关键发现**：
- **除GPT-4外，所有模型在条件句推理上都存在基本错误**
- 反事实推理面临显著挑战
- CLOMO基准（arXiv:2311.17438）揭示LLM反事实思维的局限

## 第七节 形式语义学在RAG中的应用

### 一、组合性与块语义

RAG分块可能破坏语义组合性：

```
原句："如果天气好，我们就去公园"

分块1："如果天气好"
分块2："我们就去公园"

问题：条件关系丢失
```

**解决方案**：保留语义依赖结构

### 二、类型论用于查询理解

```python
def type_based_query_parsing(query):
    """基于类型论的查询解析"""
    
    # 识别查询的语义类型
    if is_entity_query(query):  # 类型 e
        # "北京的首都是什么？"
        return retrieve_entity(query)
    
    elif is_property_query(query):  # 类型 ⟨e, t⟩
        # "哪些城市有地铁？"
        return retrieve_entities_with_property(query)
    
    elif is_relation_query(query):  # 类型 ⟨e, ⟨e, t⟩⟩
        # "谁是张三的老师？"
        return retrieve_related_entities(query)
```
