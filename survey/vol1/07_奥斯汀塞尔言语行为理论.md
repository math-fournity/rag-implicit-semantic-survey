# 第一卷 语言学与认知基础：神经-符号整合

## 回复7：奥斯汀-塞尔言语行为理论

---

### 概述与承接

上一回复系统阐述了格莱斯的会话含义理论，揭示了字面意义之外的隐含意义如何通过合作原则推导而出。本回复继续深入语用学领域，转向另一个核心理论——**言语行为理论（Speech Act Theory）**。

言语行为理论的核心洞见是：**语言不仅用于描述世界，还用于改变世界**。当我们说"我承诺明天来"时，我们不仅仅是在描述一个承诺的存在，而是**在实施承诺这个行为本身**。这种"以言行事"的观点彻底改变了我们对语言功能的理解。

对于RAG系统而言，言语行为理论提供了分析用户意图的重要框架。用户的查询不仅仅是"寻求信息"，还可能是"请求帮助"、"寻求确认"、"表达不满"等多种言语行为。准确识别言语行为的类型，是提供恰当回应的前提。本回复将系统介绍奥斯汀和塞尔的理论贡献，并探讨其在认知增强RAG系统中的应用。

### 一、奥斯汀：以言行事

#### 1.1 述行句的发现

J.L. Austin在其1962年的经典著作《如何以言行事》（*How to Do Things with Words*）中，首先挑战了哲学中长期占主导地位的观点：**语言的首要功能是描述世界**。

传统观点认为，句子的核心特征是可以被判断为真或假。"雪是白的"可以通过观察世界来验证其真假。但Austin指出，有一类句子根本不能用真假来评判：

**述行句（Performatives）**的例子：
- "我宣布会议开始。"
- "我承诺明天还钱。"
- "我命名这艘船为伊丽莎白号。"
- "我打赌明天会下雨。"

这些句子不是在描述世界的状态，而是在**执行一个行动**。当牧师说"我宣布你们结为夫妻"时，他不是在描述一个婚姻的存在，而是在**创造这个婚姻**。

Austin将传统的描述性句子称为**述谓句（Constatives）**，将这类执行行动的句子称为**述行句（Performatives）**。

#### 1.2 述行句的适切性条件

述行句不能用真/假来评判，但可以用**适切/不适切（Felicitous/Infelicitous）**来评价。Austin提出了述行句成功的**适切性条件（Felicity Conditions）**：

**A. 准备条件**
1. 必须存在一套被接受的约定程序，该程序有约定的效果，并且包括在特定情境下由特定人说出特定的话
2. 特定的人和情境必须适合于援引该程序

**B. 执行条件**
3. 程序必须被所有参与者正确地执行
4. 程序必须被完整地执行

**C. 真诚条件**
5. 参与者必须真诚地持有相关的态度、意图和情感
6. 参与者必须随后按照相关态度行事

违反这些条件会导致**不适切（Infelicity）**：

- 违反A条件：**误用（Misfire）**——行为完全无效
  - 例：非法官说"我判你有罪"无法产生法律效力
  
- 违反B条件：**误用**——行为被废止
  - 例：婚礼一方中途退场，婚姻不成立
  
- 违反C条件：**滥用（Abuse）**——行为形式上成功但不真诚
  - 例：说"我承诺"但根本不打算履行

#### 1.3 言语行为的三分法

Austin后来认识到，述行/述谓的二分法过于简单。最终，他提出了著名的**言语行为三分法**：

**言内行为（Locutionary Act）**：说出具有特定意义的话语的行为。
- 包括发声行为（发出声音）、表意行为（使用词汇和语法）、指称行为（指称事物和表达命题）

**言外行为（Illocutionary Act）**：在说话中实施的行为，即说话的"力量"或意图。
- 陈述、提问、命令、承诺、警告、感谢等

**言后行为（Perlocutionary Act）**：通过说话产生的效果或后果。
- 说服、吓唬、启发、激怒、取悦等

**例句分析**："外面在下雨。"

| 行为层面 | 分析 |
|---------|------|
| 言内行为 | 说出"外面在下雨"这句话，表达"外界正在降水"的命题 |
| 言外行为 | 陈述一个事实（可能还有：警告、建议、抱怨...） |
| 言后行为 | 使听者相信在下雨、使听者带伞出门、使听者决定不出门... |

言外行为是言语行为理论的核心，因为它涉及语言的**社会功能**和**交际意图**。

#### 1.4 Austin的言外行为分类

Austin尝试对言外行为进行分类，提出了五大类：

| 类别 | 定义 | 例子 |
|-----|------|-----|
| **裁决类（Verdictives）** | 做出判断或裁定 | 判决、估计、评价、分类 |
| **行使类（Exercitives）** | 行使权力或影响 | 命令、任命、建议、警告 |
| **承诺类（Commissives）** | 承担义务或意图 | 承诺、保证、打赌、同意 |
| **行为类（Behabitives）** | 表达态度或社会行为 | 道歉、感谢、祝贺、欢迎 |
| **阐述类（Expositives）** | 阐明观点或论证 | 断言、否认、解释、让步 |

Austin承认这个分类不够完善，存在重叠和遗漏。这为Searle后来的系统化工作留下了空间。

### 二、塞尔：言语行为的系统化

#### 2.1 言外行为的构成规则

John Searle继承并发展了Austin的理论，使之更加系统和精确。Searle的核心贡献是将言语行为分析为**规则约束的行为**。

Searle区分了两种规则：
- **调节性规则（Regulative Rules）**：调节已经存在的行为（如交通规则）
- **构成性规则（Constitutive Rules）**：创造或定义新的行为形式（如象棋规则）

言语行为受**构成性规则**的约束。实施一个言语行为，就是遵循一套定义该行为的规则。

#### 2.2 承诺的规则分析

Searle以"承诺"为例，详细分析了言语行为的构成规则：

**命题内容条件（Propositional Content Condition）**：
- 命题表达说话者的一个未来行为

**准备条件（Preparatory Conditions）**：
- 听话者希望说话者执行该行为（或至少说话者相信如此）
- 在正常情况下，说话者不会明显地执行该行为
- 说话者有能力执行该行为

**真诚条件（Sincerity Condition）**：
- 说话者真的打算执行该行为

**本质条件（Essential Condition）**：
- 该言语算作承担执行该行为的义务

这种分析揭示了"承诺"这个言语行为的本质：不仅仅是说出"我承诺..."，而是必须满足一系列条件，才能构成真正的承诺。

#### 2.3 Searle的言外行为分类

Searle提出了更为系统的五分类，基于**言外之力的要点（Illocutionary Point）**：

| 类别 | 言外要点 | 适应方向 | 心理状态 | 例子 |
|-----|---------|---------|---------|-----|
| **断言类（Assertives）** | 承诺命题的真实性 | 词→世界 | 相信 | 陈述、断言、报告 |
| **指令类（Directives）** | 使听者做某事 | 世界→词 | 希望 | 请求、命令、建议 |
| **承诺类（Commissives）** | 承诺未来行动 | 世界→词 | 意图 | 承诺、威胁、保证 |
| **表达类（Expressives）** | 表达心理状态 | 无 | 多种 | 感谢、道歉、祝贺 |
| **宣告类（Declarations）** | 改变世界状态 | 双向 | 无 | 宣布、命名、判决 |

**适应方向（Direction of Fit）**解释：
- **词→世界**：话语应该符合世界的状态（描述）
- **世界→词**：世界应该改变以符合话语（改变）
- **双向**：话语同时描述和改变世界

#### 2.4 间接言语行为

Searle的另一重要贡献是**间接言语行为（Indirect Speech Acts）**理论。

**直接言语行为**：句子的语法形式与其言外之力一致
- 陈述句 → 断言
- 疑问句 → 提问
- 祈使句 → 命令/请求

**间接言语行为**：句子的语法形式与其言外之力不一致
- "你能把盐递给我吗？"（疑问句 → 请求）
- "这里真热。"（陈述句 → 请求开窗/开空调）

间接言语行为的理解需要推理：听话者从字面意义出发，利用语境和背景知识，推导出说话者的真正意图。这与格莱斯的会话含义理论有密切联系。

### 三、言语行为与RAG系统

#### 3.1 用户查询的言语行为分析

用户向RAG系统提交的查询可以视为言语行为。准确识别其言外之力是提供恰当回应的前提。

**用户查询的常见言语行为类型**：

| 言语行为 | 典型查询形式 | 期望回应 |
|---------|-------------|---------|
| **信息请求** | "X是什么？" "如何做Y？" | 提供信息 |
| **确认请求** | "X是真的吗？" "对吗？" | 确认或否认 |
| **澄清请求** | "你是说...？" "能再解释一下吗？" | 提供更清晰的解释 |
| **建议请求** | "应该怎么办？" "推荐什么？" | 提供建议或推荐 |
| **评估请求** | "X好吗？" "A和B哪个好？" | 提供评价或比较 |
| **行动请求** | "帮我写..." "生成一个..." | 执行任务 |
| **抱怨/报告问题** | "X不工作" "出错了" | 诊断+解决方案 |

#### 3.2 言语行为识别的重要性

正确识别言语行为类型对RAG系统至关重要：

**例1：同样的命题内容，不同的言语行为**

用户："Python的GIL"

可能的言语行为：
- **信息请求**："Python的GIL是什么？"→ 需要解释
- **问题报告**："Python的GIL（导致我的多线程程序很慢）"→ 需要解决方案
- **讨论引入**："（我想谈谈）Python的GIL"→ 需要深入讨论

不同的识别会导致完全不同的检索策略和回答方式。

**例2：字面与意图的差异**

用户："你知道RAG是什么吗？"

字面言语行为：**询问系统的知识**（Yes/No问题）
实际言语行为：**请求解释RAG**

如果系统只回答"是的，我知道"，将是完全不当的回应。

#### 3.3 检索内容的言语行为标注

检索到的文档也包含各种言语行为，识别它们有助于：

- 判断内容的可信度（断言 vs. 推测）
- 识别建议和警告
- 区分事实陈述和观点表达

**文档言语行为标注示例**：

```
原文："这种方法可能不适合大规模数据集。"
言语行为：警告/限定断言
标注：[WARNING] 方法适用范围限制

原文："建议使用分批处理来解决内存问题。"
言语行为：建议
标注：[RECOMMENDATION] 解决方案

原文："实验结果表明，准确率达到95%。"
言语行为：断言（有证据支持）
标注：[CLAIM:EVIDENCED] 性能数据
```
