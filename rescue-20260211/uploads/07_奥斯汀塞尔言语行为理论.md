### 一、奥斯汀：以言行事

#### 1.1 述行句的发现

J.L. Austin在其1962年的经典著作《如何以言行事》（*How to Do Things with Words*）中，首先挑战了哲学中长期占主导地位的观点：**语言的首要功能是描述世界**。

传统观点认为，句子的核心特征是可以被判断为真或假。"雪是白的"可以通过观察世界来验证其真假。但Austin指出，有一类句子根本不能用真假来评判：

**述行句（Performatives）**的例子：
- "我宣布会议开始。"
- "我承诺明天还钱。"
- "我命名这艘船为伊丽莎白号。"
- "我打赌明天会下雨。"

这些句子不是在描述世界的状态，而是在**执行一个行动**。当牧师说"我宣布你们结为夫妻"时，他不是在描述一个婚姻的存在，而是在**创造这个婚姻**。

Austin将传统的描述性句子称为**述谓句（Constatives）**，将这类执行行动的句子称为**述行句（Performatives）**。

#### 1.2 述行句的适切性条件

述行句不能用真/假来评判，但可以用**适切/不适切（Felicitous/Infelicitous）**来评价。Austin提出了述行句成功的**适切性条件（Felicity Conditions）**：

**A. 准备条件**
1. 必须存在一套被接受的约定程序，该程序有约定的效果，并且包括在特定情境下由特定人说出特定的话
2. 特定的人和情境必须适合于援引该程序

**B. 执行条件**
3. 程序必须被所有参与者正确地执行
4. 程序必须被完整地执行

**C. 真诚条件**
5. 参与者必须真诚地持有相关的态度、意图和情感
6. 参与者必须随后按照相关态度行事

违反这些条件会导致**不适切（Infelicity）**：

- 违反A条件：**误用（Misfire）**——行为完全无效
  - 例：非法官说"我判你有罪"无法产生法律效力
  
- 违反B条件：**误用**——行为被废止
  - 例：婚礼一方中途退场，婚姻不成立
  
- 违反C条件：**滥用（Abuse）**——行为形式上成功但不真诚
  - 例：说"我承诺"但根本不打算履行

#### 1.3 言语行为的三分法

Austin后来认识到，述行/述谓的二分法过于简单。最终，他提出了著名的**言语行为三分法**：

**言内行为（Locutionary Act）**：说出具有特定意义的话语的行为。
- 包括发声行为（发出声音）、表意行为（使用词汇和语法）、指称行为（指称事物和表达命题）

**言外行为（Illocutionary Act）**：在说话中实施的行为，即说话的"力量"或意图。
- 陈述、提问、命令、承诺、警告、感谢等

**言后行为（Perlocutionary Act）**：通过说话产生的效果或后果。
- 说服、吓唬、启发、激怒、取悦等

**例句分析**："外面在下雨。"

| 行为层面 | 分析 |
|---------|------|
| 言内行为 | 说出"外面在下雨"这句话，表达"外界正在降水"的命题 |
| 言外行为 | 陈述一个事实（可能还有：警告、建议、抱怨...） |
| 言后行为 | 使听者相信在下雨、使听者带伞出门、使听者决定不出门... |

言外行为是言语行为理论的核心，因为它涉及语言的**社会功能**和**交际意图**。

#### 1.4 Austin的言外行为分类

Austin尝试对言外行为进行分类，提出了五大类：

| 类别 | 定义 | 例子 |
|-----|------|-----|
| **裁决类（Verdictives）** | 做出判断或裁定 | 判决、估计、评价、分类 |
| **行使类（Exercitives）** | 行使权力或影响 | 命令、任命、建议、警告 |
| **承诺类（Commissives）** | 承担义务或意图 | 承诺、保证、打赌、同意 |
| **行为类（Behabitives）** | 表达态度或社会行为 | 道歉、感谢、祝贺、欢迎 |
| **阐述类（Expositives）** | 阐明观点或论证 | 断言、否认、解释、让步 |

Austin承认这个分类不够完善，存在重叠和遗漏。这为Searle后来的系统化工作留下了空间。

### 二、塞尔：言语行为的系统化

#### 2.1 言外行为的构成规则

John Searle继承并发展了Austin的理论，使之更加系统和精确。Searle的核心贡献是将言语行为分析为**规则约束的行为**。

Searle区分了两种规则：
- **调节性规则（Regulative Rules）**：调节已经存在的行为（如交通规则）
- **构成性规则（Constitutive Rules）**：创造或定义新的行为形式（如象棋规则）

言语行为受**构成性规则**的约束。实施一个言语行为，就是遵循一套定义该行为的规则。

#### 2.2 承诺的规则分析

Searle以"承诺"为例，详细分析了言语行为的构成规则：

**命题内容条件（Propositional Content Condition）**：
- 命题表达说话者的一个未来行为

**准备条件（Preparatory Conditions）**：
- 听话者希望说话者执行该行为（或至少说话者相信如此）
- 在正常情况下，说话者不会明显地执行该行为
- 说话者有能力执行该行为

**真诚条件（Sincerity Condition）**：
- 说话者真的打算执行该行为

**本质条件（Essential Condition）**：
- 该言语算作承担执行该行为的义务

这种分析揭示了"承诺"这个言语行为的本质：不仅仅是说出"我承诺..."，而是必须满足一系列条件，才能构成真正的承诺。

#### 2.3 Searle的言外行为分类

Searle提出了更为系统的五分类，基于**言外之力的要点（Illocutionary Point）**：

| 类别 | 言外要点 | 适应方向 | 心理状态 | 例子 |
|-----|---------|---------|---------|-----|
| **断言类（Assertives）** | 承诺命题的真实性 | 词→世界 | 相信 | 陈述、断言、报告 |
| **指令类（Directives）** | 使听者做某事 | 世界→词 | 希望 | 请求、命令、建议 |
| **承诺类（Commissives）** | 承诺未来行动 | 世界→词 | 意图 | 承诺、威胁、保证 |
| **表达类（Expressives）** | 表达心理状态 | 无 | 多种 | 感谢、道歉、祝贺 |
| **宣告类（Declarations）** | 改变世界状态 | 双向 | 无 | 宣布、命名、判决 |

**适应方向（Direction of Fit）**解释：
- **词→世界**：话语应该符合世界的状态（描述）
- **世界→词**：世界应该改变以符合话语（改变）
- **双向**：话语同时描述和改变世界

#### 2.4 间接言语行为

Searle的另一重要贡献是**间接言语行为（Indirect Speech Acts）**理论。

**直接言语行为**：句子的语法形式与其言外之力一致
- 陈述句 → 断言
- 疑问句 → 提问
- 祈使句 → 命令/请求

**间接言语行为**：句子的语法形式与其言外之力不一致
- "你能把盐递给我吗？"（疑问句 → 请求）
- "这里真热。"（陈述句 → 请求开窗/开空调）

间接言语行为的理解需要推理：听话者从字面意义出发，利用语境和背景知识，推导出说话者的真正意图。这与格莱斯的会话含义理论有密切联系。

### 三、言语行为与RAG系统

#### 3.1 用户查询的言语行为分析

用户向RAG系统提交的查询可以视为言语行为。准确识别其言外之力是提供恰当回应的前提。

**用户查询的常见言语行为类型**：

| 言语行为 | 典型查询形式 | 期望回应 |
|---------|-------------|---------|
| **信息请求** | "X是什么？" "如何做Y？" | 提供信息 |
| **确认请求** | "X是真的吗？" "对吗？" | 确认或否认 |
| **澄清请求** | "你是说...？" "能再解释一下吗？" | 提供更清晰的解释 |
| **建议请求** | "应该怎么办？" "推荐什么？" | 提供建议或推荐 |
| **评估请求** | "X好吗？" "A和B哪个好？" | 提供评价或比较 |
| **行动请求** | "帮我写..." "生成一个..." | 执行任务 |
| **抱怨/报告问题** | "X不工作" "出错了" | 诊断+解决方案 |

#### 3.2 言语行为识别的重要性

正确识别言语行为类型对RAG系统至关重要：

**例1：同样的命题内容，不同的言语行为**

用户："Python的GIL"

可能的言语行为：
- **信息请求**："Python的GIL是什么？"→ 需要解释
- **问题报告**："Python的GIL（导致我的多线程程序很慢）"→ 需要解决方案
- **讨论引入**："（我想谈谈）Python的GIL"→ 需要深入讨论

不同的识别会导致完全不同的检索策略和回答方式。

**例2：字面与意图的差异**

用户："你知道RAG是什么吗？"

字面言语行为：**询问系统的知识**（Yes/No问题）
实际言语行为：**请求解释RAG**

如果系统只回答"是的，我知道"，将是完全不当的回应。

#### 3.3 检索内容的言语行为标注

检索到的文档也包含各种言语行为，识别它们有助于：

- 判断内容的可信度（断言 vs. 推测）
- 识别建议和警告
- 区分事实陈述和观点表达

**文档言语行为标注示例**：

```
原文："这种方法可能不适合大规模数据集。"
言语行为：警告/限定断言
标注：[WARNING] 方法适用范围限制

原文："建议使用分批处理来解决内存问题。"
言语行为：建议
标注：[RECOMMENDATION] 解决方案

原文："实验结果表明，准确率达到95%。"
言语行为：断言（有证据支持）
标注：[CLAIM:EVIDENCED] 性能数据
```

### 四、言语行为识别系统

#### 4.1 规则基础的识别

```python
"""
言语行为识别系统

基于规则和模式匹配的言语行为识别
"""

from dataclasses import dataclass
from typing import List, Dict, Optional, Tuple
from enum import Enum
import re


class SpeechActType(Enum):
    """言语行为类型枚举
    
    基于Searle的五分类，扩展为适合对话系统的细分类
    """
    # 断言类（Assertives）
    ASSERTION = "assertion"              # 断言
    CLAIM = "claim"                      # 声称
    REPORT = "report"                    # 报告
    EXPLANATION = "explanation"          # 解释
    
    # 指令类（Directives）
    REQUEST_INFO = "request_info"        # 信息请求
    REQUEST_ACTION = "request_action"    # 行动请求
    REQUEST_CONFIRM = "request_confirm"  # 确认请求
    REQUEST_CLARIFY = "request_clarify"  # 澄清请求
    REQUEST_SUGGEST = "request_suggest"  # 建议请求
    COMMAND = "command"                  # 命令
    
    # 承诺类（Commissives）
    PROMISE = "promise"                  # 承诺
    OFFER = "offer"                      # 提议
    
    # 表达类（Expressives）
    THANK = "thank"                      # 感谢
    APOLOGIZE = "apologize"              # 道歉
    COMPLAIN = "complain"                # 抱怨
    GREET = "greet"                      # 问候
    
    # 宣告类（Declarations）
    DECLARE = "declare"                  # 宣告
    
    # 未知
    UNKNOWN = "unknown"


@dataclass
class SpeechActAnalysis:
    """言语行为分析结果"""
    primary_act: SpeechActType
    confidence: float
    secondary_acts: List[Tuple[SpeechActType, float]]
    propositional_content: str
    illocutionary_indicators: List[str]


class RuleBasedSpeechActRecognizer:
    """基于规则的言语行为识别器"""
    
    def __init__(self):
        # 言语行为指示词模式
        self.patterns = {
            # 信息请求模式
            SpeechActType.REQUEST_INFO: [
                r"^(什么|谁|哪|何|怎么|如何|为什么|多少|几)",
                r"(是什么|怎么样|怎样|如何|为何)",
                r"^(请|能否|可以).*(解释|说明|介绍|讲讲)",
                r"(告诉我|让我知道|想知道|想了解)",
            ],
            
            # 确认请求模式
            SpeechActType.REQUEST_CONFIRM: [
                r"(对吗|对不对|是吗|是不是|是否|真的吗)",
                r"^(是不是|能不能确认|请确认)",
                r"(正确吗|没错吧)",
            ],
            
            # 行动请求模式
            SpeechActType.REQUEST_ACTION: [
                r"^(请|帮我|帮忙|麻烦)",
                r"(写一个|生成|创建|制作|编写)",
                r"(能不能|可以|能否).*(帮|做|写|生成)",
            ],
            
            # 建议请求模式
            SpeechActType.REQUEST_SUGGEST: [
                r"(推荐|建议|应该|该怎么)",
                r"(哪个好|哪个更好|选择|选哪个)",
                r"(有什么好的|有什么推荐)",
            ],
            
            # 抱怨/问题报告模式
            SpeechActType.COMPLAIN: [
                r"(不工作|不行|出错|报错|失败|问题)",
                r"(无法|不能|没法|做不到)",
                r"(为什么不|怎么不)",
            ],
            
            # 感谢模式
            SpeechActType.THANK: [
                r"(谢谢|感谢|多谢|thanks|thank)",
            ],
            
            # 问候模式
            SpeechActType.GREET: [
                r"^(你好|您好|hi|hello|hey)",
                r"(早上好|下午好|晚上好)",
            ],
        }
        
        # 编译正则表达式
        self.compiled_patterns = {
            act_type: [re.compile(p, re.IGNORECASE) for p in patterns]
            for act_type, patterns in self.patterns.items()
        }
    
    def recognize(self, text: str) -> SpeechActAnalysis:
        """识别言语行为
        
        Args:
            text: 输入文本
            
        Returns:
            言语行为分析结果
        """
        text = text.strip()
        matches = []
        indicators = []
        
        # 模式匹配
        for act_type, patterns in self.compiled_patterns.items():
            for pattern in patterns:
                if pattern.search(text):
                    matches.append(act_type)
                    indicators.append(pattern.pattern)
                    break  # 每个类型只匹配一次
        
        # 确定主要言语行为
        if matches:
            # 优先级排序
            priority = [
                SpeechActType.REQUEST_ACTION,
                SpeechActType.REQUEST_INFO,
                SpeechActType.REQUEST_SUGGEST,
                SpeechActType.REQUEST_CONFIRM,
                SpeechActType.COMPLAIN,
                SpeechActType.THANK,
                SpeechActType.GREET,
            ]
            
            for act in priority:
                if act in matches:
                    primary = act
                    break
            else:
                primary = matches[0]
            
            confidence = 0.9 if len(matches) == 1 else 0.7
            secondary = [(act, 0.5) for act in matches if act != primary]
        else:
            # 默认为断言或信息请求
            if "?" in text or "？" in text:
                primary = SpeechActType.REQUEST_INFO
            else:
                primary = SpeechActType.ASSERTION
            confidence = 0.5
            secondary = []
        
        return SpeechActAnalysis(
            primary_act=primary,
            confidence=confidence,
            secondary_acts=secondary,
            propositional_content=self._extract_propositional_content(text),
            illocutionary_indicators=indicators
        )
    
    def _extract_propositional_content(self, text: str) -> str:
        """提取命题内容（简化实现）"""
        # 移除言语行为指示词
        content = text
        remove_patterns = [
            r"^(请|帮我|帮忙|麻烦|能否|可以)",
            r"(吗|呢|吧|呀)$",
            r"^(什么是|如何|怎么|为什么)",
        ]
        for pattern in remove_patterns:
            content = re.sub(pattern, "", content)
        return content.strip()


class NeuralSpeechActRecognizer:
    """基于神经网络的言语行为识别器
    
    使用预训练语言模型进行分类
    """
    
    def __init__(self, model_name: str = "bert-base-chinese"):
        """初始化
        
        Args:
            model_name: 预训练模型名称
        """
        self.model_name = model_name
        self.labels = list(SpeechActType)
        # 实际实现需要加载训练好的分类模型
        self.model = None
    
    def recognize(self, text: str) -> SpeechActAnalysis:
        """神经网络识别（需要训练数据）"""
        # 简化实现：使用规则方法作为后备
        rule_recognizer = RuleBasedSpeechActRecognizer()
        return rule_recognizer.recognize(text)


class HybridSpeechActRecognizer:
    """混合言语行为识别器
    
    结合规则和神经网络方法
    """
    
    def __init__(self):
        self.rule_recognizer = RuleBasedSpeechActRecognizer()
        self.neural_recognizer = NeuralSpeechActRecognizer()
    
    def recognize(
        self, 
        text: str,
        use_neural: bool = False
    ) -> SpeechActAnalysis:
        """识别言语行为
        
        Args:
            text: 输入文本
            use_neural: 是否使用神经网络方法
            
        Returns:
            言语行为分析结果
        """
        rule_result = self.rule_recognizer.recognize(text)
        
        if use_neural and self.neural_recognizer.model is not None:
            neural_result = self.neural_recognizer.recognize(text)
            # 融合结果
            return self._fuse_results(rule_result, neural_result)
        
        return rule_result
    
    def _fuse_results(
        self,
        rule_result: SpeechActAnalysis,
        neural_result: SpeechActAnalysis
    ) -> SpeechActAnalysis:
        """融合规则和神经网络结果"""
        # 如果一致，提高置信度
        if rule_result.primary_act == neural_result.primary_act:
            return SpeechActAnalysis(
                primary_act=rule_result.primary_act,
                confidence=min(0.95, rule_result.confidence + 0.1),
                secondary_acts=rule_result.secondary_acts,
                propositional_content=rule_result.propositional_content,
                illocutionary_indicators=rule_result.illocutionary_indicators
            )
        
        # 不一致时，使用置信度更高的
        if neural_result.confidence > rule_result.confidence:
            return neural_result
        return rule_result

        result = recognizer.recognize(query)
        print(f"\n查询: '{query}'")
        print(f"  主要言语行为: {result.primary_act.value}")
        print(f"  置信度: {result.confidence:.2f}")
        print(f"  命题内容: {result.propositional_content}")
        if result.secondary_acts:
            print(f"  次要言语行为: {[a[0].value for a in result.secondary_acts]}")


if __name__ == "__main__":
    demo_speech_act_recognition()
```

#### 4.2 言语行为引导的回应生成

```python
"""
言语行为引导的回应策略

根据识别出的言语行为类型选择适当的回应策略
"""

from dataclasses import dataclass
from typing import List, Dict, Callable, Any


@dataclass
class ResponseStrategy:
    """回应策略"""
    response_type: str
    required_elements: List[str]
    optional_elements: List[str]
    tone: str
    format_hint: str


class SpeechActResponsePlanner:
    """言语行为回应规划器"""
    
    def __init__(self):
        # 言语行为到回应策略的映射
        self.strategies = {
            SpeechActType.REQUEST_INFO: ResponseStrategy(
                response_type="information_provision",
                required_elements=["定义/解释", "核心概念"],
                optional_elements=["示例", "相关概念", "参考资源"],
                tone="informative",
                format_hint="结构化解释，可使用列表或分段"
            ),
            
            SpeechActType.REQUEST_ACTION: ResponseStrategy(
                response_type="task_execution",
                required_elements=["任务结果", "执行说明"],
                optional_elements=["使用注意", "替代方案"],
                tone="helpful",
                format_hint="直接提供结果，附带必要说明"
            ),
            
            SpeechActType.REQUEST_CONFIRM: ResponseStrategy(
                response_type="confirmation",
                required_elements=["明确确认/否认", "依据说明"],
                optional_elements=["补充信息", "例外情况"],
                tone="clear",
                format_hint="先明确回答是/否，再解释"
            ),
            
            SpeechActType.REQUEST_SUGGEST: ResponseStrategy(
                response_type="recommendation",
                required_elements=["推荐选项", "推荐理由"],
                optional_elements=["比较分析", "适用场景", "注意事项"],
                tone="advisory",
                format_hint="提供选项，说明各自优缺点"
            ),
            
            SpeechActType.COMPLAIN: ResponseStrategy(
                response_type="problem_solving",
                required_elements=["问题确认", "原因分析", "解决方案"],
                optional_elements=["预防措施", "相关资源"],
                tone="empathetic",
                format_hint="先共情，再诊断，最后提供方案"
            ),
            
            SpeechActType.THANK: ResponseStrategy(
                response_type="acknowledgment",
                required_elements=["礼貌回应"],
                optional_elements=["进一步帮助的提议"],
                tone="friendly",
                format_hint="简短友好"
            ),
            
            SpeechActType.GREET: ResponseStrategy(
                response_type="greeting",
                required_elements=["回应问候"],
                optional_elements=["询问需求"],
                tone="welcoming",
                format_hint="简短热情"
            ),
        }
    
    def plan_response(
        self, 
        speech_act: SpeechActAnalysis
    ) -> ResponseStrategy:
        """规划回应策略
        
        Args:
            speech_act: 言语行为分析结果
            
        Returns:
            回应策略
        """
        primary = speech_act.primary_act
        
        if primary in self.strategies:
            return self.strategies[primary]
        
        # 默认策略
        return ResponseStrategy(
            response_type="general",
            required_elements=["相关信息"],
            optional_elements=["补充说明"],
            tone="neutral",
            format_hint="根据内容自适应"
        )
    
    def generate_response_prompt(
        self,
        query: str,
        speech_act: SpeechActAnalysis,
        retrieved_content: str
    ) -> str:
        """生成回应提示词
        
        Args:
            query: 用户查询
            speech_act: 言语行为分析
            retrieved_content: 检索到的内容
            
        Returns:
            生成回应的提示词
        """
        strategy = self.plan_response(speech_act)
        
        prompt = f"""
你需要根据用户的查询生成回应。

## 用户查询
{query}

## 言语行为分析
- 类型: {speech_act.primary_act.value}
- 命题内容: {speech_act.propositional_content}

## 回应策略
- 回应类型: {strategy.response_type}
- 必须包含: {', '.join(strategy.required_elements)}
- 可选包含: {', '.join(strategy.optional_elements)}
- 语气: {strategy.tone}
- 格式提示: {strategy.format_hint}

## 检索到的相关内容
{retrieved_content}

## 要求
1. 严格按照回应策略生成回应
2. 必须包含所有"必须包含"的元素
3. 根据内容丰富度决定是否包含可选元素
4. 保持适当的语气
5. 遵循格式提示

请生成回应：
"""
        return prompt


class SpeechActAwareGenerator:
    """言语行为感知的回答生成器"""
    
    def __init__(self, llm: Any = None):
        self.llm = llm
        self.planner = SpeechActResponsePlanner()
        self.recognizer = HybridSpeechActRecognizer()
    
    def generate(
        self,
        query: str,
        retrieved_content: str
    ) -> str:
        """生成言语行为感知的回答
        
        Args:
            query: 用户查询
            retrieved_content: 检索内容
            
        Returns:
            生成的回答
        """
        # 1. 识别言语行为
        speech_act = self.recognizer.recognize(query)
        
        # 2. 生成提示词
        prompt = self.planner.generate_response_prompt(
            query,
            speech_act,
            retrieved_content
        )
        
        # 3. 生成回答（简化：直接返回策略信息）
        if self.llm:
            return self.llm.generate(prompt)
        
        # 演示用：返回策略概要
        strategy = self.planner.plan_response(speech_act)
        return f"""
[言语行为: {speech_act.primary_act.value}]
[回应类型: {strategy.response_type}]
[语气: {strategy.tone}]

根据检索内容生成的回答将包含:
- {chr(10).join('- ' + e for e in strategy.required_elements)}
"""
```

### 五、言语行为在对话RAG中的应用

#### 5.1 多轮对话中的言语行为序列

在多轮对话中，言语行为形成**序列**，存在**期望-满足**的关系：

**相邻对（Adjacency Pairs）**：
- 问题 → 回答
- 请求 → 接受/拒绝
- 问候 → 问候
- 道歉 → 接受/拒绝

RAG系统应该追踪对话中未被满足的言语行为，确保对话的完整性。

```python
"""
对话言语行为追踪器

追踪多轮对话中的言语行为序列和满足状态
"""

from dataclasses import dataclass, field
from typing import List, Optional
from enum import Enum


class FulfillmentStatus(Enum):
    """满足状态"""
    PENDING = "pending"        # 待满足
    FULFILLED = "fulfilled"    # 已满足
    PARTIALLY = "partially"    # 部分满足
    ABANDONED = "abandoned"    # 已放弃


@dataclass
class DialogueAct:
    """对话中的言语行为"""
    turn_id: int
    speaker: str  # "user" or "system"
    text: str
    speech_act: SpeechActType
    fulfillment: FulfillmentStatus = FulfillmentStatus.PENDING
    fulfilled_by: Optional[int] = None  # 满足它的turn_id


@dataclass
class DialogueState:
    """对话状态"""
    acts: List[DialogueAct] = field(default_factory=list)
    pending_requests: List[int] = field(default_factory=list)
    current_topic: Optional[str] = None


class DialogueActTracker:
    """对话言语行为追踪器"""
    
    # 期望的回应类型
    EXPECTED_RESPONSES = {
        SpeechActType.REQUEST_INFO: [SpeechActType.ASSERTION, SpeechActType.EXPLANATION],
        SpeechActType.REQUEST_CONFIRM: [SpeechActType.ASSERTION],
        SpeechActType.REQUEST_ACTION: [SpeechActType.ASSERTION, SpeechActType.OFFER],
        SpeechActType.REQUEST_SUGGEST: [SpeechActType.ASSERTION, SpeechActType.OFFER],
        SpeechActType.GREET: [SpeechActType.GREET],
        SpeechActType.THANK: [SpeechActType.ASSERTION],  # "不客气"等
    }
    
    def __init__(self):
        self.state = DialogueState()
        self.recognizer = HybridSpeechActRecognizer()
    
    def add_turn(
        self, 
        speaker: str, 
        text: str
    ) -> DialogueAct:
        """添加一个对话轮次
        
        Args:
            speaker: 说话者
            text: 文本
            
        Returns:
            对话言语行为
        """
        turn_id = len(self.state.acts)
        speech_act_analysis = self.recognizer.recognize(text)
        
        act = DialogueAct(
            turn_id=turn_id,
            speaker=speaker,
            text=text,
            speech_act=speech_act_analysis.primary_act
        )
        
        self.state.acts.append(act)
        
        # 更新满足状态
        if speaker == "user":
            # 用户的请求添加到待满足列表
            if act.speech_act in self.EXPECTED_RESPONSES:
                self.state.pending_requests.append(turn_id)
        else:
            # 系统回应可能满足之前的请求
            self._check_fulfillment(act)
        
        return act
    
    def _check_fulfillment(self, system_act: DialogueAct):
        """检查系统回应是否满足了待处理的请求"""
        fulfilled = []
        
        for req_id in self.state.pending_requests:
            req_act = self.state.acts[req_id]
            expected = self.EXPECTED_RESPONSES.get(req_act.speech_act, [])
            
            if system_act.speech_act in expected:
                req_act.fulfillment = FulfillmentStatus.FULFILLED
                req_act.fulfilled_by = system_act.turn_id
                fulfilled.append(req_id)
        
        # 从待处理列表中移除已满足的
        for req_id in fulfilled:
            self.state.pending_requests.remove(req_id)
    
    def get_pending_requests(self) -> List[DialogueAct]:
        """获取所有未满足的请求"""
        return [
            self.state.acts[i] 
            for i in self.state.pending_requests
        ]
    
    def get_dialogue_summary(self) -> Dict:
        """获取对话摘要"""
        return {
            "total_turns": len(self.state.acts),
            "pending_requests": len(self.state.pending_requests),
            "fulfilled_requests": sum(
                1 for act in self.state.acts 
                if act.fulfillment == FulfillmentStatus.FULFILLED
            ),
            "user_acts": [
                act.speech_act.value 
                for act in self.state.acts 
                if act.speaker == "user"
            ],
            "system_acts": [
                act.speech_act.value 
                for act in self.state.acts 
                if act.speaker == "system"
            ]
        }


# 演示
def demo_dialogue_tracking():
    """演示对话追踪"""
    print("=" * 60)
    print("对话言语行为追踪演示")
    print("=" * 60)
    
    tracker = DialogueActTracker()
    
    # 模拟对话
    dialogue = [
        ("user", "你好"),
        ("system", "你好！有什么可以帮助你的吗？"),
        ("user", "什么是RAG？"),
        ("system", "RAG是检索增强生成的缩写，它结合了信息检索和语言模型..."),
        ("user", "有什么推荐的实现框架吗？"),
        ("system", "推荐使用LlamaIndex或LangChain，它们都提供了完善的RAG支持..."),
        ("user", "谢谢"),
        ("system", "不客气！还有其他问题吗？"),
    ]
    
    for speaker, text in dialogue:
        act = tracker.add_turn(speaker, text)
        print(f"\n[{speaker}] {text}")
        print(f"  言语行为: {act.speech_act.value}")
        print(f"  满足状态: {act.fulfillment.value}")
    
    print("\n" + "=" * 60)
    print("对话摘要:")
    summary = tracker.get_dialogue_summary()
    for key, value in summary.items():
        print(f"  {key}: {value}")
    
    pending = tracker.get_pending_requests()
    print(f"\n未满足的请求: {len(pending)}")
    for req in pending:
        print(f"  - [{req.turn_id}] {req.text}")


if __name__ == "__main__":
    demo_dialogue_tracking()
```
