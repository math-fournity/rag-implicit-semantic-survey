### 一、融合的理论动机

#### 1.1 两种范式的互补性

形式语义学与分布式语义学的对立并非不可调和。深入分析后，我们发现它们实际上是**互补的**：

| 维度 | 形式语义学 | 分布式语义学 | 融合目标 |
|-----|-----------|-------------|---------|
| **意义本体** | 外延对象、真值条件 | 高维向量空间 | 结构化向量表示 |
| **获取方式** | 人工定义、规则构建 | 数据驱动、自动学习 | 半监督结构学习 |
| **组合机制** | 函数应用、类型驱动 | 向量运算（常无语法约束） | 类型化张量运算 |
| **优势** | 精确、可解释、可推理 | 鲁棒、可扩展、覆盖广 | 精确且鲁棒 |
| **劣势** | 脆弱、覆盖有限 | 难解释、推理弱 | 互补克服 |

关键洞见是：**形式结构可以作为分布式表示的归纳偏置（Inductive Bias）**，而**分布式表示可以为形式结构提供概率化的实现**。

#### 1.2 Baroni的"Frege in Space"计划

Baroni, Bernardi & Zamparelli (2014) 提出了影响深远的**"Frege in Space"**研究计划，试图将Frege的组合性原则与向量空间语义学统一起来。

其核心主张是：

> 分布式语义模型可以遵循组合性原则，复合表达式的向量由其组成部分的向量和句法组合规则共同决定。

这个计划的理论框架是：
1. 词汇项由向量/张量表示
2. 句法结构决定张量收缩（Tensor Contraction）方式
3. 组合结果是新的向量/张量

例如，形容词-名词组合：

$$\vec{red\_car} = A_{red} \cdot \vec{car}$$

其中 $A_{red}$ 是一个矩阵（二阶张量），$\vec{car}$ 是名词的向量，矩阵-向量乘法产生组合后的向量。

#### 1.3 DisCoCat：范畴论视角

Coecke, Sadrzadeh & Clark (2010) 从**范畴论（Category Theory）**的视角提出了**DisCoCat（Distributional Compositional Categorical）**框架，为形式-分布融合提供了数学基础。

DisCoCat的关键思想：
- **Lambek预群语法**提供句法结构
- **向量空间**提供语义解释
- **范畴论函子**连接句法与语义

在这个框架中，**介词语法（Pregroup Grammar）**的类型对应于向量空间的张量积：

$$n \otimes s \otimes n^r \mapsto N \otimes S \otimes N$$

其中 $n$ 是名词类型，$s$ 是句子类型，$N$ 和 $S$ 是对应的向量空间。

DisCoCat的优雅之处在于：句法推导的图示化表示（String Diagrams）可以直接对应于张量网络的收缩计算，句法和语义通过范畴论的工具自然统一。

### 二、类型化张量模型

#### 2.1 从向量到张量

标准的词嵌入将词映射到固定维度的向量。但组合性语义需要更丰富的表示：不同类型的词应该有不同阶的表示。

**类型-张量对应**：
- 名词（类型 $n$）→ 向量（1阶张量）：$\vec{n} \in \mathbb{R}^d$
- 形容词（类型 $n/n$）→ 矩阵（2阶张量）：$A \in \mathbb{R}^{d \times d}$
- 及物动词（类型 $(n\backslash s)/n$）→ 3阶张量：$T \in \mathbb{R}^{d \times d \times d}$

这种对应保证了组合的类型正确性：

$$\text{形容词} \cdot \text{名词} = \text{矩阵} \times \text{向量} = \text{向量}$$

#### 2.2 句子向量的组合计算

考虑句子"Dogs chase cats"的组合计算：

**词汇表示**：
- $\vec{dogs} \in \mathbb{R}^d$（主语名词向量）
- $T_{chase} \in \mathbb{R}^{d \times d \times d}$（及物动词张量）
- $\vec{cats} \in \mathbb{R}^d$（宾语名词向量）

**组合计算**：

$$\vec{sentence} = \sum_{ijk} T_{chase}^{ijk} \cdot dogs_i \cdot cats_j \cdot \vec{e_k}$$

或用张量收缩记号：

$$\vec{sentence} = T_{chase} \times_1 \vec{dogs} \times_2 \vec{cats}$$

这个计算保证了：
- 句子向量的维度与名词相同
- 不同的主语、宾语产生不同的句子向量
- 动词张量编码了动作的语义结构

#### 2.3 张量的学习与分解

直接学习高阶张量面临**参数爆炸**问题。一个3阶张量需要 $d^3$ 个参数（$d=300$ 时为2700万）。

**解决方案1：矩阵分解**

将动词张量分解为低秩形式：

$$T_{verb} = \sum_{r=1}^{R} \vec{u_r} \otimes \vec{v_r} \otimes \vec{w_r}$$

其中 $R \ll d$ 是秩，每个分量是三个向量的外积。参数量从 $d^3$ 降至 $3Rd$。

**解决方案2：神经网络参数化**

使用神经网络生成张量：

$$T_{verb} = f_{NN}(\vec{verb})$$

词向量通过网络映射到张量，共享网络参数大幅减少参数量。

**解决方案3：注意力机制替代**

Transformer的注意力机制可以视为一种软性的张量运算：

$$Attention(Q, K, V) = softmax(\frac{QK^T}{\sqrt{d}})V$$

查询-键-值的三方交互隐式地编码了张量结构。

#### 2.4 实验验证与效果

类型化张量模型在多个任务上展现了优势：

**句子相似度**：
- SICK数据集上，张量组合模型优于简单加法/乘法模型
- 能够区分"dog bites man"和"man bites dog"

**蕴含识别**：
- 能够捕获词序敏感的蕴含关系
- 对否定词的处理更为准确

**句法歧义消解**：
- 利用类型信息指导组合顺序
- 减少歧义解析的错误

### 三、神经语义解析

#### 3.1 从符号到神经的语义解析

**语义解析（Semantic Parsing）**将自然语言映射到形式语义表示（如一阶逻辑、Lambda演算、SQL等）。传统方法依赖手工规则和特征工程，而**神经语义解析**使用端到端的神经网络学习这一映射。

神经语义解析的基本架构：

```
自然语言 → 编码器 → 解码器 → 形式表示
   |           |          |         |
 "Who wrote   BERT/     seq2seq/   λx.∃y.wrote(y,x)
  Hamlet?"    T5        Tree       ∧ hamlet(y)
```

主流方法包括：

**Seq2Seq方法**：将语义解析视为序列到序列的翻译任务。输入是自然语言句子，输出是线性化的逻辑形式。

**Seq2Tree方法**：解码器生成树结构而非序列，更好地匹配逻辑形式的层次结构。

**Grammar-Constrained解码**：使用语法约束限制解码空间，确保输出是合法的逻辑形式。

#### 3.2 Text-to-SQL：实用的语义解析

Text-to-SQL是神经语义解析最成功的应用场景之一，将自然语言问题转换为SQL查询。

**代表性数据集**：
- Spider：跨域、复杂查询
- WikiSQL：单表简单查询
- BIRD：真实世界数据库

**代表性模型**：

**RAT-SQL**（Wang et al., 2020）：使用关系感知的Transformer编码问题和数据库schema，通过图神经网络建模表-列-值的关系。

**PICARD**（Scholak et al., 2021）：使用T5作为基座，加入增量解析约束，确保生成的SQL语法正确。

**DIN-SQL**（Pourreza & Rafiei, 2023）：将复杂问题分解为子问题，逐步生成SQL，利用LLM的推理能力。

**2024年进展**：
- LLM直接生成SQL的准确率显著提升
- 上下文学习（ICL）配合少量示例即可达到良好效果
- RAG增强：检索相似问题-SQL对作为示例

#### 3.3 AMR与语义图解析

**抽象意义表示（Abstract Meaning Representation, AMR）**是另一种重要的语义形式化，使用有根有向无环图表示句子意义。

AMR示例：
```
句子："The boy wants to go"

AMR图：
(w / want-01
  :ARG0 (b / boy)
  :ARG1 (g / go-02
    :ARG0 b))
```

**AMR解析的神经方法**：

**Transition-based方法**：使用栈-缓冲区数据结构，逐步构建AMR图。

**Seq2Graph方法**：将图线性化为PENMAN记号，使用seq2seq生成。

**Graph Neural Networks**：使用GNN直接预测节点和边。

AMR对RAG的意义：
- 提供抽象的、规范化的意义表示
- 支持跨句的实体和事件对齐
- 为语义检索提供结构化查询

语义解析可以增强RAG系统的多个环节：

### 四、可微分逻辑与神经符号推理

#### 4.1 从离散到连续的推理

传统逻辑推理是离散的、符号化的，难以与神经网络的连续优化框架结合。**可微分逻辑（Differentiable Logic）**通过将逻辑运算"软化"为可微分的操作，实现了逻辑推理与梯度学习的统一。

**软化逻辑运算**：

| 硬逻辑 | 软逻辑（积范数） | 软逻辑（Gödel范数） |
|-------|-----------------|-------------------|
| $\neg a$ | $1 - a$ | $1 - a$ |
| $a \land b$ | $a \cdot b$ | $\min(a, b)$ |
| $a \lor b$ | $a + b - ab$ | $\max(a, b)$ |
| $a \rightarrow b$ | $1 - a + ab$ | $\min(1, 1-a+b)$ |

这里 $a, b \in [0, 1]$ 表示真值的连续化。

#### 4.2 Neural Theorem Provers

**Neural Theorem Provers (NTP)**（Rocktäschel & Riedel, 2017）将定理证明过程神经网络化。

核心思想：
- 符号作为嵌入向量
- 统一（Unification）作为可微分的相似度计算
- 证明成功概率通过前向传播计算

证明规则的软化：

$$prove(goal) = \sum_{rule} \alpha_{rule} \cdot prove(body_{rule})$$

其中 $\alpha_{rule}$ 是规则的适用度，通过神经网络计算。

#### 4.3 Logic Tensor Networks

**Logic Tensor Networks (LTN)**（Badreddine et al., 2022）是神经符号推理的代表性框架，将一阶逻辑公式转化为张量计算。

LTN的核心组件：

**Grounding**：将常量、变量、谓词映射到张量：
- 常量 → 向量：$\mathcal{G}(john) = \vec{v_{john}}$
- 谓词 → 神经网络：$\mathcal{G}(Human(x)) = f_{Human}(\vec{x})$

**公式评估**：
$$\mathcal{G}(\forall x. Human(x) \rightarrow Mortal(x)) = \prod_{x \in D} (1 - f_{Human}(\vec{x}) + f_{Human}(\vec{x}) \cdot f_{Mortal}(\vec{x}))$$

**学习目标**：最大化知识库中公式的满足度：
$$\max_\theta \sum_{\phi \in KB} \mathcal{G}_\theta(\phi)$$

#### 4.4 神经符号RAG

将可微分逻辑引入RAG系统可以实现：

**逻辑约束的检索**：
```python
# 检索满足逻辑约束的文档
constraint = "∀x. relevant(x, query) ∧ recent(x) → retrieve(x)"
# 软化为可微分形式
def soft_constraint(doc, query):
    relevance = compute_relevance(doc, query)
    recency = compute_recency(doc)
    return min(1, 1 - relevance * recency + retrieve_score(doc))
```

**推理增强的生成**：
```python
# 在生成时强制逻辑一致性
# 如果前提P成立且P→Q成立，则结论必须包含Q
def logic_constrained_generate(premises, rules, query):
    inferred = apply_rules(premises, rules)  # 逻辑推理
    context = premises + inferred  # 增强上下文
    return generate(context, query)  # 约束生成
```

### 五、融合框架的工程实现

#### 5.1 统一语义表示层

为RAG系统设计统一的语义表示层，同时支持向量和结构化表示：

```python
"""
统一语义表示层

融合分布式表示与形式语义结构，
为RAG系统提供丰富的语义表示。

核心设计：
1. 向量表示：捕获分布式语义
2. 结构表示：捕获组合语义
3. 类型信息：约束组合方式

时间复杂度：
- 向量编码：O(L * d)，L为序列长度，d为维度
- 结构解析：O(L^3)（CKY解析）或 O(L)（神经解析）
- 融合表示：O(d^2)（张量运算）
"""

from dataclasses import dataclass, field
from typing import List, Dict, Optional, Any, Tuple
from abc import ABC, abstractmethod
from enum import Enum
import numpy as np


class SemanticTypeEnum(Enum):
    """语义类型枚举"""
    ENTITY = "e"              # 实体
    PREDICATE = "e_t"         # 一元谓词 (e → t)
    RELATION = "e_e_t"        # 二元关系 (e → e → t)
    MODIFIER = "e_t_e_t"      # 修饰语 ((e → t) → (e → t))
    SENTENCE = "t"            # 句子/命题
    QUANTIFIER = "q"          # 量词
    UNKNOWN = "?"             # 未知类型


@dataclass
class SemanticType:
    """语义类型"""
    base_type: SemanticTypeEnum
    subtype: Optional[str] = None  # 细分类型，如 "person", "location"
    
    def __str__(self) -> str:
        if self.subtype:
            return f"{self.base_type.value}:{self.subtype}"
        return self.base_type.value


@dataclass
class VectorRepresentation:
    """向量表示"""
    vector: np.ndarray
    dimension: int
    model_source: str = "unknown"
    
    def similarity(self, other: 'VectorRepresentation') -> float:
        """计算余弦相似度"""
        dot = np.dot(self.vector, other.vector)
        norm1 = np.linalg.norm(self.vector)
        norm2 = np.linalg.norm(other.vector)
        return dot / (norm1 * norm2 + 1e-10)


@dataclass
class StructuralRepresentation:
    """结构化表示"""
    predicate: str
    arguments: List['UnifiedSemanticUnit'] = field(default_factory=list)
    modifiers: List['UnifiedSemanticUnit'] = field(default_factory=list)
    
    def to_logical_form(self) -> str:
        """转换为逻辑形式字符串"""
        if not self.arguments:
            return self.predicate
        args = ", ".join(arg.text for arg in self.arguments)
        return f"{self.predicate}({args})"


@dataclass
class UnifiedSemanticUnit:
    """统一语义单元
    
    融合向量表示和结构化表示的核心数据结构
    """
    text: str                                    # 原始文本
    semantic_type: SemanticType                  # 语义类型
    vector_repr: Optional[VectorRepresentation] = None    # 向量表示
    struct_repr: Optional[StructuralRepresentation] = None  # 结构表示
    confidence: float = 1.0                      # 置信度
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    def has_vector(self) -> bool:
        return self.vector_repr is not None
    
    def has_structure(self) -> bool:
        return self.struct_repr is not None
    
    def get_hybrid_score(
        self, 
        other: 'UnifiedSemanticUnit',
        vector_weight: float = 0.7,
        struct_weight: float = 0.3
    ) -> float:
        """计算混合相似度
        
        Args:
            other: 另一个语义单元
            vector_weight: 向量相似度权重
            struct_weight: 结构相似度权重
            
        Returns:
            混合相似度分数
        """
        score = 0.0
        total_weight = 0.0
        
        # 向量相似度
        if self.has_vector() and other.has_vector():
            vec_sim = self.vector_repr.similarity(other.vector_repr)
            score += vector_weight * vec_sim
            total_weight += vector_weight
        
        # 结构相似度（简化实现）
        if self.has_structure() and other.has_structure():
            struct_sim = self._compute_struct_similarity(
                self.struct_repr, 
                other.struct_repr
            )
            score += struct_weight * struct_sim
            total_weight += struct_weight
        
        return score / total_weight if total_weight > 0 else 0.0
    
    def _compute_struct_similarity(
        self, 
        s1: StructuralRepresentation,
        s2: StructuralRepresentation
    ) -> float:
        """计算结构相似度"""
        # 谓词匹配
        pred_match = 1.0 if s1.predicate == s2.predicate else 0.0
        
        # 参数匹配（Jaccard相似度）
        args1 = set(arg.text for arg in s1.arguments)
        args2 = set(arg.text for arg in s2.arguments)
        if args1 or args2:
            arg_sim = len(args1 & args2) / len(args1 | args2)
        else:
            arg_sim = 1.0
        
        return 0.5 * pred_match + 0.5 * arg_sim


class SemanticComposer:
    """语义组合器
    
    根据类型规则组合语义单元
    """
    
    # 组合规则：(输入类型1, 输入类型2) -> 输出类型
    COMPOSITION_RULES = {
        (SemanticTypeEnum.MODIFIER, SemanticTypeEnum.PREDICATE): SemanticTypeEnum.PREDICATE,
        (SemanticTypeEnum.PREDICATE, SemanticTypeEnum.ENTITY): SemanticTypeEnum.SENTENCE,
        (SemanticTypeEnum.RELATION, SemanticTypeEnum.ENTITY): SemanticTypeEnum.PREDICATE,
        (SemanticTypeEnum.QUANTIFIER, SemanticTypeEnum.PREDICATE): SemanticTypeEnum.SENTENCE,
    }
    
    def __init__(self, vector_dim: int = 256):
        """初始化
        
        Args:
            vector_dim: 向量维度
        """
        self.vector_dim = vector_dim
        # 组合矩阵（简化：使用随机初始化，实际应训练）
        self.composition_matrices = {}
    
    def compose(
        self, 
        unit1: UnifiedSemanticUnit, 
        unit2: UnifiedSemanticUnit
    ) -> Optional[UnifiedSemanticUnit]:
        """组合两个语义单元
        
        Args:
            unit1: 第一个单元（函数项）
            unit2: 第二个单元（参数项）
            
        Returns:
            组合后的语义单元，类型不兼容则返回None
        """
        # 检查类型兼容性
        type_pair = (unit1.semantic_type.base_type, unit2.semantic_type.base_type)
        if type_pair not in self.COMPOSITION_RULES:
            return None
        
        result_type = self.COMPOSITION_RULES[type_pair]
        
        # 组合文本
        combined_text = f"{unit1.text} {unit2.text}"
        
        # 组合向量表示
        combined_vector = None
        if unit1.has_vector() and unit2.has_vector():
            combined_vector = self._compose_vectors(
                unit1.vector_repr.vector,
                unit2.vector_repr.vector,
                type_pair
            )
        
        # 组合结构表示
        combined_struct = None
        if unit1.has_structure():
            combined_struct = StructuralRepresentation(
                predicate=unit1.struct_repr.predicate,
                arguments=unit1.struct_repr.arguments + [unit2],
                modifiers=unit1.struct_repr.modifiers
            )
        
        return UnifiedSemanticUnit(
            text=combined_text,
            semantic_type=SemanticType(result_type),
            vector_repr=VectorRepresentation(
                vector=combined_vector,
                dimension=self.vector_dim,
                model_source="composed"
            ) if combined_vector is not None else None,
            struct_repr=combined_struct,
            confidence=unit1.confidence * unit2.confidence
        )
    
    def _compose_vectors(
        self, 
        v1: np.ndarray, 
        v2: np.ndarray,
        type_pair: Tuple[SemanticTypeEnum, SemanticTypeEnum]
    ) -> np.ndarray:
        """向量组合
        
        使用类型化的组合矩阵（简化实现）
        """
        # 获取或创建组合矩阵
        if type_pair not in self.composition_matrices:
            # 初始化为单位矩阵的变体
            np.random.seed(hash(type_pair) % 2**32)
            self.composition_matrices[type_pair] = (
                np.eye(self.vector_dim) + 
                0.1 * np.random.randn(self.vector_dim, self.vector_dim)
            )
        
        matrix = self.composition_matrices[type_pair]
        
        # 组合方式：矩阵作用于拼接向量后投影
        # 简化实现：加权平均 + 非线性
        combined = 0.6 * v1 + 0.4 * v2
        combined = np.tanh(np.dot(matrix, combined))
        
        # 归一化
        combined = combined / (np.linalg.norm(combined) + 1e-10)
        
        return combined


class UnifiedSemanticAnalyzer:
    """统一语义分析器
    
    将文本转换为统一语义表示
    """
    
    def __init__(
        self, 
        embedding_model: Any = None,
        parser: Any = None
    ):
        """初始化
        
        Args:
            embedding_model: 嵌入模型
            parser: 语义解析器
        """
        self.embedding_model = embedding_model
        self.parser = parser
        self.composer = SemanticComposer()
        
        # 简单的类型词典
        self.type_lexicon = {
            # 实体
            "john": SemanticType(SemanticTypeEnum.ENTITY, "person"),
            "mary": SemanticType(SemanticTypeEnum.ENTITY, "person"),
            "book": SemanticType(SemanticTypeEnum.ENTITY, "object"),
            # 谓词
            "student": SemanticType(SemanticTypeEnum.PREDICATE, "property"),
            "runs": SemanticType(SemanticTypeEnum.PREDICATE, "action"),
            # 关系
            "loves": SemanticType(SemanticTypeEnum.RELATION, "emotion"),
            "wrote": SemanticType(SemanticTypeEnum.RELATION, "action"),
            # 修饰语
            "red": SemanticType(SemanticTypeEnum.MODIFIER, "color"),
            "big": SemanticType(SemanticTypeEnum.MODIFIER, "size"),
            # 量词
            "every": SemanticType(SemanticTypeEnum.QUANTIFIER, "universal"),
            "some": SemanticType(SemanticTypeEnum.QUANTIFIER, "existential"),
        }
    
    def analyze(self, text: str) -> List[UnifiedSemanticUnit]:
        """分析文本，生成语义单元列表
        
        Args:
            text: 输入文本
            
        Returns:
            语义单元列表
        """
        units = []
        
        # 简化：按词分析
        words = text.lower().split()
        
        for word in words:
            # 确定类型
            sem_type = self.type_lexicon.get(
                word, 
                SemanticType(SemanticTypeEnum.UNKNOWN)
            )
            
            # 生成向量表示（模拟）
            np.random.seed(hash(word) % 2**32)
            vector = np.random.randn(256)
            vector = vector / np.linalg.norm(vector)
            
            vec_repr = VectorRepresentation(
                vector=vector,
                dimension=256,
                model_source="simulated"
            )
            
            # 生成结构表示
            struct_repr = StructuralRepresentation(
                predicate=word,
                arguments=[],
                modifiers=[]
            )
            
            unit = UnifiedSemanticUnit(
                text=word,
                semantic_type=sem_type,
                vector_repr=vec_repr,
                struct_repr=struct_repr
            )
            
            units.append(unit)
        
        return units
    
    def compose_phrase(
        self, 
        units: List[UnifiedSemanticUnit]
    ) -> Optional[UnifiedSemanticUnit]:
        """组合短语
        
        Args:
            units: 语义单元列表
            
        Returns:
            组合后的语义单元
        """
        if not units:
            return None
        
        if len(units) == 1:
            return units[0]
        
        # 从左到右组合
        result = units[0]
        for i in range(1, len(units)):
            composed = self.composer.compose(result, units[i])
            if composed:
                result = composed
            else:
                # 组合失败，使用简单拼接
                result = UnifiedSemanticUnit(
                    text=f"{result.text} {units[i].text}",
                    semantic_type=SemanticType(SemanticTypeEnum.UNKNOWN),
                    vector_repr=result.vector_repr,  # 保留第一个的向量
                    struct_repr=None
                )
        
        return result
```

#### 5.2 融合检索架构

```python
"""
融合检索架构

结合向量检索和结构化查询的混合检索系统

时间复杂度：
- 向量检索：O(log n)（HNSW）
- 结构化查询：O(m)（m为匹配规则数）
- 融合排序：O(k log k)（k为候选数）
"""

from dataclasses import dataclass
from typing import List, Dict, Optional, Tuple, Callable
import numpy as np


@dataclass
class Document:
    """文档"""
    id: str
    text: str
    vector: Optional[np.ndarray] = None
    structured_repr: Optional[Dict] = None  # 结构化表示
    metadata: Dict = None


@dataclass
class Query:
    """查询"""
    text: str
    vector: Optional[np.ndarray] = None
    structured_repr: Optional[Dict] = None  # 解析后的结构化查询
    constraints: List[Callable] = None  # 逻辑约束


@dataclass
class RetrievalResult:
    """检索结果"""
    doc: Document
    vector_score: float = 0.0
    struct_score: float = 0.0
    constraint_score: float = 1.0
    final_score: float = 0.0


class HybridRetriever:
    """混合检索器
    
    融合向量检索、结构化匹配和逻辑约束
    """
    
    def __init__(
        self,
        vector_index: 'VectorIndex',
        struct_matcher: 'StructureMatcher',
        vector_weight: float = 0.5,
        struct_weight: float = 0.3,
        constraint_weight: float = 0.2
    ):
        """初始化
        
        Args:
            vector_index: 向量索引
            struct_matcher: 结构匹配器
            vector_weight: 向量检索权重
            struct_weight: 结构匹配权重
            constraint_weight: 约束满足权重
        """
        self.vector_index = vector_index
        self.struct_matcher = struct_matcher
        self.weights = {
            'vector': vector_weight,
            'struct': struct_weight,
            'constraint': constraint_weight
        }
        self.documents: Dict[str, Document] = {}
    
    def index_document(self, doc: Document):
        """索引文档"""
        self.documents[doc.id] = doc
        
        if doc.vector is not None:
            self.vector_index.add(doc.vector, doc.id)
        
        if doc.structured_repr is not None:
            self.struct_matcher.index(doc.id, doc.structured_repr)
    
    def retrieve(
        self, 
        query: Query, 
        top_k: int = 10,
        vector_candidates: int = 100
    ) -> List[RetrievalResult]:
        """混合检索
        
        Args:
            query: 查询对象
            top_k: 返回数量
            vector_candidates: 向量检索召回数量
            
        Returns:
            排序后的检索结果
        """
        candidates: Dict[str, RetrievalResult] = {}
        
        # 阶段1：向量检索召回
        if query.vector is not None:
            vector_results = self.vector_index.search(
                query.vector, 
                top_k=vector_candidates
            )
            for doc_id, score in vector_results:
                if doc_id in self.documents:
                    candidates[doc_id] = RetrievalResult(
                        doc=self.documents[doc_id],
                        vector_score=score
                    )
        
        # 阶段2：结构化匹配
        if query.structured_repr is not None:
            struct_results = self.struct_matcher.match(
                query.structured_repr,
                top_k=vector_candidates
            )
            for doc_id, score in struct_results:
                if doc_id in candidates:
                    candidates[doc_id].struct_score = score
                elif doc_id in self.documents:
                    candidates[doc_id] = RetrievalResult(
                        doc=self.documents[doc_id],
                        struct_score=score
                    )
        
        # 阶段3：约束检查
        if query.constraints:
            for doc_id, result in candidates.items():
                constraint_scores = []
                for constraint in query.constraints:
                    try:
                        score = constraint(result.doc)
                        constraint_scores.append(score)
                    except:
                        constraint_scores.append(0.0)
                
                if constraint_scores:
                    result.constraint_score = np.mean(constraint_scores)
        
        # 阶段4：融合排序
        for result in candidates.values():
            result.final_score = (
                self.weights['vector'] * result.vector_score +
                self.weights['struct'] * result.struct_score +
                self.weights['constraint'] * result.constraint_score
            )
        
        # 排序并返回
        sorted_results = sorted(
            candidates.values(),
            key=lambda x: x.final_score,
            reverse=True
        )
        
        return sorted_results[:top_k]


class StructureMatcher:
    """结构匹配器
    
    基于谓词-论元结构的匹配
    """
    
    def __init__(self):
        self.predicate_index: Dict[str, List[str]] = {}  # 谓词 -> 文档ID列表
        self.doc_structures: Dict[str, Dict] = {}  # 文档ID -> 结构
    
    def index(self, doc_id: str, structure: Dict):
        """索引文档结构"""
        self.doc_structures[doc_id] = structure
        
        # 提取谓词建立索引
        if 'predicates' in structure:
            for pred in structure['predicates']:
                if pred not in self.predicate_index:
                    self.predicate_index[pred] = []
                self.predicate_index[pred].append(doc_id)
    
    def match(
        self, 
        query_struct: Dict, 
        top_k: int = 100
    ) -> List[Tuple[str, float]]:
        """结构匹配
        
        Args:
            query_struct: 查询结构
            top_k: 返回数量
            
        Returns:
            (文档ID, 匹配分数)列表
        """
        scores: Dict[str, float] = {}
        
        # 基于谓词匹配
        if 'predicates' in query_struct:
            for pred in query_struct['predicates']:
                if pred in self.predicate_index:
                    for doc_id in self.predicate_index[pred]:
                        scores[doc_id] = scores.get(doc_id, 0) + 1.0
        
        # 归一化
        if query_struct.get('predicates'):
            max_score = len(query_struct['predicates'])
            for doc_id in scores:
                scores[doc_id] /= max_score
        
        # 排序返回
        sorted_results = sorted(
            scores.items(),
            key=lambda x: x[1],
            reverse=True
        )
        
        return sorted_results[:top_k]
```
