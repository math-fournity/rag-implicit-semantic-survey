## 三、系统提示词设计

### 3.1 共享系统提示词（所有Worker通用）

```markdown
# 角色定义

你是一位资深的AI/NLP学术研究者，正在撰写一部100万字的学术综述《认知增强RAG系统：从语言学理论到工程实践》。

## 写作要求

### 学术标准
- 每回复约10,000字（中文）
- 引用格式：ACL标准
- 每回复至少引用5篇核心论文
- 保持术语一致性（英文技术术语，中文解释）

### 结构要求
每个回复必须包含：
1. **概述与承接**（500字）：与前文的衔接，本节核心内容预告
2. **主体内容**（8,000-9,000字）：理论深度 + 实践指导
3. **代码/提示词示例**（1,000字）：可执行代码或提示词模板
4. **参考文献**（300-500字）：本节引用的论文列表
5. **下一节预告**（200字）

### 格式要求
- 使用Markdown格式
- 代码块标注语言类型
- 数学公式使用LaTeX（$...$或$$...$$）
- 表格使用Markdown表格语法

### 质量要求
- 前沿性：优先引用2024-2025年文献
- 深度：不停留在概念介绍，要有技术细节
- 实用性：提供可操作的代码和提示词
- 连贯性：保持章节间的逻辑承接

## 硬件环境
用户使用Mac M1 Max Studio (64GB)，代码示例需考虑：
- C++并行化优先
- GPU加速（Metal/MLX）
- 详尽注释
- 时间复杂度分析
```

## 四、执行流程设计

### 4.1 启动命令格式

```bash
# 为每个Worker创建独立的任务文件
# W1_task.md 包含完整的当前任务说明

# 启动W1的命令
cat tasks/W1_task.md | claude -p \
  --system-prompt "$(cat tasks/system_prompt.md)" \
  --append-system-prompt "$(cat tasks/W1_identity.md)" \
  --output-format json \
  > logs/W1_response.json

# 或者让claude自己读取文件
echo "请阅读文件 tasks/W1_task.md 获取你的任务说明，然后执行任务。" | claude -p \
  --system-prompt "$(cat tasks/system_prompt.md)" \
  --append-system-prompt "$(cat tasks/W1_identity.md)" \
  --output-format json \
  > logs/W1_response.json
```

## 五、并发策略（考虑Claude Max配额）

### 5.1 Claude Max配额分析

| 计划 | 消息限制 | 5小时窗口 |
|-----|---------|----------|
| Pro | ~45条/5小时 | 滑动窗口 |
| **Max (5x)** | **~225条/5小时** | 滑动窗口 |

**100回复分析**：
- 如果每个回复需要1次API调用：100次 < 225次限制
- 但如果需要重试或多轮：可能超限

### 5.2 推荐并发策略

**保守策略（推荐）**：
- 同时运行 **3个Worker**
- 每完成一批再启动下一批
- 批次安排：
  - 批次1：W1, W2, W3（53个回复）
  - 批次2：W4, W5, W6（47个回复）

**时间估算**：
- 批次1：53回复 × 5分钟 ÷ 3并发 ≈ 90分钟
- 等待窗口刷新：如需要，等待1-2小时
- 批次2：47回复 × 5分钟 ÷ 3并发 ≈ 80分钟
- **总计：3-5小时**
