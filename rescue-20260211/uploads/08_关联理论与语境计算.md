### 概述与承接

前两回复系统介绍了格莱斯的会话含义理论和奥斯汀-塞尔的言语行为理论，建立了语用学分析的基础框架。本回复转向另一个影响深远的语用学理论——**关联理论（Relevance Theory）**，由Dan Sperber和Deirdre Wilson在1986年提出。

关联理论从**认知科学**的角度重新审视语用学，提出了一个核心问题：**在众多可能的解释中，听话者是如何快速、准确地找到说话者意图的解释的？**答案是：人类交际受到**关联性**的引导——我们倾向于寻找以最小认知努力获取最大认知效果的解释。

对于RAG系统而言，关联理论提供了**语境选择**和**信息呈现**的理论基础。在检索阶段，如何判断哪些信息与用户查询"关联"？在生成阶段，如何组织信息使其最容易被理解？关联理论的原则提供了明确的指导。本回复将深入解析关联理论的核心概念，并探讨其在认知增强RAG系统中的应用。

### 一、关联理论的核心概念

#### 1.1 对格莱斯理论的批评与发展

关联理论并非对格莱斯理论的否定，而是批判性的发展。Sperber和Wilson认为格莱斯理论存在几个问题：

**四条准则的非独立性**：格莱斯的四条准则（数量、质量、关系、方式）看似独立，实际上都可以归结为一条——**关联性**。说足够的话、说真话、说相关的话、说清楚的话，本质上都是为了实现有效的关联。

**准则的描述性而非解释性**：格莱斯理论描述了交际者应该遵守什么规范，却没有解释**为什么**他们会遵守，以及**如何**推导含义。

**语境的黑箱问题**：格莱斯理论假设语境是给定的，却没有说明语境是如何被选择和构建的。

关联理论试图用一个统一的**关联原则**来解释所有语用现象，并且给出认知层面的机制解释。

#### 1.2 认知效果与加工努力

关联理论的两个核心概念是**认知效果（Cognitive Effects）**和**加工努力（Processing Effort）**。

**认知效果**是指一个输入对个体的认知环境产生的改变。主要类型包括：

- **强化（Strengthening）**：加强已有的假设
- **弱化（Weakening）**：削弱已有的假设
- **否定（Contradiction）**：消除已有的假设
- **语境蕴涵（Contextual Implication）**：产生新的推论

认知效果越大，信息越有价值。

**加工努力**是指理解一个输入所需要的心智资源，包括：

- 解析语言结构的努力
- 提取语境信息的努力
- 进行推理的努力
- 整合信息的努力

加工努力越小，理解越容易。

#### 1.3 关联的定义

关联理论对"关联"给出了精确的定义：

> **定义（关联性）**：一个输入对于个体来说是关联的，当且仅当它的加工能够产生正面的认知效果。

关联性是一个**比较概念**，可以在两个条件下比较：

> **条件1**：在相同的加工努力下，认知效果越大，关联性越强。
> 
> **条件2**：在相同的认知效果下，加工努力越小，关联性越强。

简言之，**关联性 = 认知效果 / 加工努力**（一种非正式的表述）。

#### 1.4 关联的两条原则

关联理论提出了两条核心原则：

**认知关联原则（Cognitive Principle of Relevance）**：
> 人类认知倾向于追求关联性的最大化。

这是关于人类认知系统的一般性声明：我们的注意力被关联性高的刺激所吸引，我们的推理过程倾向于产生关联性高的结论。

**交际关联原则（Communicative Principle of Relevance）**：
> 每一个明示的交际行为都传达了关于其自身最佳关联性的假定。

这是关于交际的原则：当说话者明确地进行交际时（而不仅仅是提供信息），他们承诺了自己的话语是值得听话者加工的——即至少能产生足够的认知效果来回报加工努力。

"最佳关联性（Optimal Relevance）"的定义是：
- 话语足够关联，值得听话者花费加工努力
- 话语是说话者愿意并且能够做到的最关联的

### 二、语境与理解过程

#### 2.1 语境的认知定义

传统语用学中，"语境"通常指物理环境、社会情境、语言上下文等。关联理论给出了不同的定义：

> **语境**是听话者在理解话语时使用的一组假设。

语境不是外在的"背景知识"，而是理解过程中**实际被激活和使用**的心理表征。关键点在于：

- 语境是**心理构建物**，而非客观存在
- 语境在理解过程中被**动态选择**和构建
- 不同的语境选择导致不同的理解

#### 2.2 理解过程的模型

关联理论提出了话语理解的**推理模型**：

```
输入：话语的语言形式
   ↓
解码：获取话语的逻辑形式（语义表征）
   ↓
语境选择：选择相关的语境假设
   ↓
推理：基于逻辑形式和语境进行推论
   ↓
输出：完整的理解（显义+隐义）
```

理解过程遵循**关联引导的启发式（Relevance-guided heuristic）**：

> 按照可及性（Accessibility）顺序测试解释；
> 当找到一个满足关联期望的解释时停止。

这意味着听话者：
1. 首先考虑最容易获取的语境假设
2. 检验是否能得到满足关联期望的解释
3. 如果能，则接受这个解释；如果不能，则扩展语境继续尝试

#### 2.3 显义与隐义

关联理论区分了理解的两个层面：

**显义（Explicature）**：通过解码和推理得出的话语的明确内容。包括：
- 消歧（选择词汇意义）
- 指称赋值（确定代词所指）
- 充实（补充省略内容）
- 调整（扩展或收缩词义）

**隐义（Implicature）**：通过纯推理得出的隐含内容。包括：
- 语境前提（Implicated Premises）
- 语境结论（Implicated Conclusions）

**例子分析**：

```
A: "你饿吗？"
B: "我早餐没吃。"
```

B的回答的显义：
- 说话者B在今天早上没有吃早餐（指称赋值：今天、B）

B的回答的隐义：
- 语境前提：如果一个人没吃早餐，他现在可能饿了
- 语境结论：B现在可能饿了

注意：隐义的推导依赖于语境假设，而这些假设是听话者根据关联性选择的。

### 三、关联理论与RAG系统

#### 3.1 检索中的关联性判断

RAG系统的检索阶段本质上是在判断**哪些文档与用户查询关联**。关联理论提供了理论框架：

**认知效果维度**：
- 文档是否能回答用户的问题？（强信息增益）
- 文档是否能补充用户已知的信息？（适度增益）
- 文档是否只是重复用户已知的？（低增益）

**加工努力维度**：
- 文档的表达是否清晰？（低努力）
- 文档是否需要大量背景知识才能理解？（高努力）
- 文档的长度和复杂度如何？（可变努力）

**关联性评分**可以形式化为：

$$Relevance(d, q, u) = \frac{CognitiveEffect(d, q, u)}{ProcessingEffort(d, u)}$$

其中 $d$ 是文档，$q$ 是查询，$u$ 是用户（的认知状态）。

#### 3.2 语境构建与动态选择

用户的查询隐含了一个**语境框架**，RAG系统需要识别并利用这个框架：

```python
"""
基于关联理论的语境构建器

动态构建和选择理解用户查询所需的语境假设
"""

from dataclasses import dataclass, field
from typing import List, Dict, Set, Optional, Tuple
from enum import Enum
import numpy as np


class AssumptionType(Enum):
    """假设类型"""
    ENCYCLOPEDIC = "encyclopedic"  # 百科知识
    LOGICAL = "logical"            # 逻辑知识
    LEXICAL = "lexical"            # 词汇知识
    SITUATIONAL = "situational"    # 情境知识
    DISCOURSE = "discourse"        # 语篇知识


@dataclass
class ContextualAssumption:
    """语境假设"""
    content: str
    assumption_type: AssumptionType
    accessibility: float  # 可及性分数 (0-1)
    source: str           # 来源
    strength: float = 1.0 # 假设强度
    
    def __hash__(self):
        return hash(self.content)


@dataclass
class RelevanceScore:
    """关联性评分"""
    cognitive_effect: float
    processing_effort: float
    relevance: float
    
    @classmethod
    def compute(cls, effect: float, effort: float) -> 'RelevanceScore':
        """计算关联性"""
        # 避免除零
        effort = max(effort, 0.01)
        relevance = effect / effort
        return cls(
            cognitive_effect=effect,
            processing_effort=effort,
            relevance=relevance
        )


class ContextBuilder:
    """语境构建器
    
    基于关联理论动态构建语境假设集合
    """
    
    def __init__(self):
        # 假设库
        self.assumption_pool: Dict[str, ContextualAssumption] = {}
        
        # 当前激活的语境
        self.active_context: Set[str] = set()
        
        # 默认百科知识（示例）
        self._init_encyclopedic_knowledge()
    
    def _init_encyclopedic_knowledge(self):
        """初始化百科知识假设"""
        encyclopedia = [
            ("RAG结合检索和生成", AssumptionType.ENCYCLOPEDIC, 0.9),
            ("向量数据库用于相似度搜索", AssumptionType.ENCYCLOPEDIC, 0.8),
            ("LLM可能产生幻觉", AssumptionType.ENCYCLOPEDIC, 0.85),
            ("Python是流行的编程语言", AssumptionType.ENCYCLOPEDIC, 0.95),
        ]
        
        for content, atype, accessibility in encyclopedia:
            assumption = ContextualAssumption(
                content=content,
                assumption_type=atype,
                accessibility=accessibility,
                source="encyclopedic_knowledge"
            )
            self.assumption_pool[content] = assumption
    
    def add_assumption(self, assumption: ContextualAssumption):
        """添加假设到假设库"""
        self.assumption_pool[assumption.content] = assumption
    
    def activate_context(
        self, 
        query: str,
        max_assumptions: int = 10
    ) -> List[ContextualAssumption]:
        """根据查询激活相关语境
        
        按照可及性顺序激活假设
        
        Args:
            query: 用户查询
            max_assumptions: 最大激活假设数
            
        Returns:
            激活的语境假设列表
        """
        # 计算每个假设与查询的相关性
        scored_assumptions = []
        
        for content, assumption in self.assumption_pool.items():
            # 简化：基于关键词匹配计算相关性
            relevance = self._compute_relevance(query, assumption)
            if relevance > 0:
                scored_assumptions.append((assumption, relevance))
        
        # 按可及性和相关性排序
        scored_assumptions.sort(
            key=lambda x: x[0].accessibility * x[1],
            reverse=True
        )
        
        # 激活前N个
        activated = []
        for assumption, _ in scored_assumptions[:max_assumptions]:
            self.active_context.add(assumption.content)
            activated.append(assumption)
        
        return activated
    
    def _compute_relevance(
        self, 
        query: str, 
        assumption: ContextualAssumption
    ) -> float:
        """计算假设与查询的相关性（简化实现）"""
        query_words = set(query.lower().split())
        assumption_words = set(assumption.content.lower().split())
        
        overlap = len(query_words & assumption_words)
        if not query_words:
            return 0
        return overlap / len(query_words)
    
    def expand_context(
        self,
        current_context: List[ContextualAssumption],
        direction: str = "related"
    ) -> List[ContextualAssumption]:
        """扩展语境
        
        当当前语境不足以得出关联解释时，扩展语境
        
        Args:
            current_context: 当前语境
            direction: 扩展方向
            
        Returns:
            扩展后的语境
        """
        new_assumptions = []
        
        for assumption in current_context:
            # 查找相关假设
            for content, pool_assumption in self.assumption_pool.items():
                if content not in self.active_context:
                    # 检查是否相关
                    if self._are_related(assumption, pool_assumption):
                        new_assumptions.append(pool_assumption)
                        self.active_context.add(content)
        
        return current_context + new_assumptions
    
    def _are_related(
        self,
        assumption1: ContextualAssumption,
        assumption2: ContextualAssumption
    ) -> bool:
        """判断两个假设是否相关"""
        words1 = set(assumption1.content.lower().split())
        words2 = set(assumption2.content.lower().split())
        return len(words1 & words2) > 0


class RelevanceBasedRetriever:
    """基于关联理论的检索器"""
    
    def __init__(
        self,
        context_builder: ContextBuilder,
        base_retriever: Any = None
    ):
        self.context_builder = context_builder
        self.base_retriever = base_retriever
    
    def retrieve(
        self,
        query: str,
        documents: List[Dict],
        top_k: int = 5
    ) -> List[Tuple[Dict, RelevanceScore]]:
        """基于关联性检索
        
        Args:
            query: 用户查询
            documents: 候选文档
            top_k: 返回数量
            
        Returns:
            (文档, 关联性评分)列表
        """
        # 1. 构建语境
        context = self.context_builder.activate_context(query)
        context_text = " ".join([a.content for a in context])
        
        # 2. 评估每个文档的关联性
        scored_docs = []
        
        for doc in documents:
            score = self._evaluate_relevance(
                query, 
                doc, 
                context
            )
            scored_docs.append((doc, score))
        
        # 3. 按关联性排序
        scored_docs.sort(key=lambda x: x[1].relevance, reverse=True)
        
        return scored_docs[:top_k]
    
    def _evaluate_relevance(
        self,
        query: str,
        doc: Dict,
        context: List[ContextualAssumption]
    ) -> RelevanceScore:
        """评估文档的关联性
        
        Args:
            query: 查询
            doc: 文档
            context: 语境假设
            
        Returns:
            关联性评分
        """
        content = doc.get("content", "")
        
        # 计算认知效果
        cognitive_effect = self._compute_cognitive_effect(
            query, 
            content, 
            context
        )
        
        # 计算加工努力
        processing_effort = self._compute_processing_effort(
            content,
            context
        )
        
        return RelevanceScore.compute(cognitive_effect, processing_effort)
    
    def _compute_cognitive_effect(
        self,
        query: str,
        content: str,
        context: List[ContextualAssumption]
    ) -> float:
        """计算认知效果
        
        考虑：
        - 信息增益（新信息量）
        - 假设强化（与已有假设一致）
        - 语境蕴涵（能产生新推论）
        """
        effect = 0.0
        
        # 信息增益：文档与查询的相关性
        query_words = set(query.lower().split())
        content_words = set(content.lower().split())
        if query_words:
            effect += len(query_words & content_words) / len(query_words)
        
        # 假设强化：与语境假设的一致性
        for assumption in context:
            assumption_words = set(assumption.content.lower().split())
            if assumption_words & content_words:
                effect += 0.2 * assumption.strength
        
        return min(effect, 1.0)
    
    def _compute_processing_effort(
        self,
        content: str,
        context: List[ContextualAssumption]
    ) -> float:
        """计算加工努力
        
        考虑：
        - 文本长度
        - 词汇复杂度
        - 所需背景知识
        """
        effort = 0.1  # 基础努力
        
        # 长度因素
        words = content.split()
        effort += len(words) / 1000  # 每1000词增加1.0努力
        
        # 词汇复杂度（简化：平均词长）
        if words:
            avg_word_len = sum(len(w) for w in words) / len(words)
            effort += (avg_word_len - 4) * 0.1  # 平均词长超过4增加努力
        
        # 语境支持度：语境越多，努力越小
        context_coverage = len(context) / 10  # 假设10个假设为充分语境
        effort *= (1 - 0.3 * min(context_coverage, 1.0))
        
        return max(effort, 0.1)
```

#### 3.3 生成中的关联性优化

生成回答时，关联理论指导我们追求**最佳关联性**：

```python
"""
关联性优化的回答生成器

生成最佳关联性的回答
"""

from dataclasses import dataclass
from typing import List, Dict, Optional


@dataclass
class GenerationConstraints:
    """生成约束"""
    max_length: int = 500
    min_cognitive_effect: float = 0.5
    max_processing_effort: float = 0.8


class RelevanceOptimizedGenerator:
    """关联性优化生成器"""
    
    def __init__(self, llm: Any = None):
        self.llm = llm
        self.constraints = GenerationConstraints()
    
    def generate(
        self,
        query: str,
        retrieved_docs: List[Dict],
        user_context: List[ContextualAssumption]
    ) -> str:
        """生成最佳关联性的回答
        
        Args:
            query: 用户查询
            retrieved_docs: 检索到的文档
            user_context: 用户语境假设
            
        Returns:
            生成的回答
        """
        # 1. 选择最关联的信息
        selected_info = self._select_relevant_info(
            query,
            retrieved_docs,
            user_context
        )
        
        # 2. 组织信息以最小化加工努力
        organized_info = self._organize_for_easy_processing(
            selected_info,
            user_context
        )
        
        # 3. 生成回答
        prompt = self._build_generation_prompt(
            query,
            organized_info,
            user_context
        )
        
        # 简化实现：返回组织后的信息
        return organized_info
    
    def _select_relevant_info(
        self,
        query: str,
        docs: List[Dict],
        context: List[ContextualAssumption]
    ) -> List[str]:
        """选择最关联的信息
        
        遵循原则：
        - 优先选择认知效果高的信息
        - 避免冗余（已在语境中的信息）
        - 避免过度信息（超出需要的）
        """
        selected = []
        context_contents = {a.content for a in context}
        
        for doc in docs:
            content = doc.get("content", "")
            
            # 检查是否与语境冗余
            if content in context_contents:
                continue
            
            # 检查是否与查询相关
            if self._is_relevant_to_query(content, query):
                selected.append(content)
        
        return selected[:5]  # 限制数量
    
    def _is_relevant_to_query(
        self, 
        content: str, 
        query: str
    ) -> bool:
        """判断内容是否与查询相关"""
        query_words = set(query.lower().split())
        content_words = set(content.lower().split())
        return len(query_words & content_words) > 0
    
    def _organize_for_easy_processing(
        self,
        info_list: List[str],
        context: List[ContextualAssumption]
    ) -> str:
        """组织信息以便于加工
        
        原则：
        - 从已知到未知
        - 从简单到复杂
        - 保持连贯性
        """
        if not info_list:
            return "未找到相关信息。"
        
        # 简化实现：直接连接
        organized = "\n\n".join(info_list)
        
        return organized
    
    def _build_generation_prompt(
        self,
        query: str,
        organized_info: str,
        context: List[ContextualAssumption]
    ) -> str:
        """构建生成提示词"""
        
        context_summary = ", ".join([a.content for a in context[:3]])
        
        prompt = f"""
基于关联理论原则生成回答。

## 关联性要求

1. **认知效果最大化**：
   - 提供用户真正需要的信息
   - 避免重复用户已知的内容
   - 产生有价值的新推论

2. **加工努力最小化**：
   - 使用清晰简洁的语言

   - 与用户的语境假设对接

## 用户查询

请生成回答：

        return prompt
```

### 四、显义计算与语境充实

#### 4.1 显义的计算过程

关联理论强调，即使是话语的"字面意义"也需要语用推理来确定。显义的计算包括：

**消歧（Disambiguation）**：选择词汇的正确意义

```
"我去银行了" → 银行（金融机构）vs 银行（河岸）
基于语境选择最关联的意义
```

**指称赋值（Reference Assignment）**：确定指示词的所指

```
"他昨天来了" → "他"指谁？"昨天"是哪一天？
基于语境中最可及的指称对象
```

**充实（Enrichment）**：补充省略或隐含的内容

```
"我吃过了" → 吃过了[某顿饭，在某个时间]
基于语境补充适当的内容
```

**调整（Loosening/Narrowing）**：调整词义的外延

```
"这本书很厚" → "厚"的具体标准？
基于语境调整为适当的程度
```

#### 4.2 在RAG中的应用

用户查询的显义计算对于准确检索至关重要：

```python
"""
查询显义计算器

计算用户查询的完整显义
"""

from dataclasses import dataclass
from typing import List, Dict, Optional, Tuple


@dataclass
class ExplicatureResult:
    """显义计算结果"""
    original: str
    disambiguated: str
    references_resolved: Dict[str, str]
    enriched: str
    full_explicature: str


class ExplicatureComputer:
    """显义计算器"""
    
    def __init__(self):
        # 歧义词典
        self.ambiguous_terms = {
            "python": ["Python编程语言", "蟒蛇"],
            "java": ["Java编程语言", "爪哇岛", "咖啡"],
            "apple": ["苹果公司", "苹果(水果)"],
            "银行": ["金融机构", "河岸"],
        }
        
        # 代词解析规则
        self.pronoun_rules = {
            "它": "根据上文最近提及的非人实体",
            "这": "根据上文最近提及的事物或情况",
            "那": "根据上文较早提及的事物",
        }
    
    def compute(
        self,
        query: str,
        context: List[ContextualAssumption],
        dialogue_history: List[str] = None
    ) -> ExplicatureResult:
        """计算查询的显义
        
        Args:
            query: 用户查询
            context: 语境假设
            dialogue_history: 对话历史
            
        Returns:
            显义计算结果
        """
        dialogue_history = dialogue_history or []
        
        # 1. 消歧
        disambiguated, disambiguations = self._disambiguate(
            query, 
            context
        )
        
        # 2. 指称赋值
        resolved, references = self._resolve_references(
            disambiguated,
            context,
            dialogue_history
        )
        
        # 3. 充实
        enriched = self._enrich(resolved, context)
        
        # 4. 组合完整显义
        full_explicature = self._compose_explicature(
            query,
            disambiguated,
            references,
            enriched
        )
        
        return ExplicatureResult(
            original=query,
            disambiguated=disambiguated,
            references_resolved=references,
            enriched=enriched,
            full_explicature=full_explicature
        )
    
    def _disambiguate(
        self,
        query: str,
        context: List[ContextualAssumption]
    ) -> Tuple[str, Dict[str, str]]:
        """消歧"""
        disambiguated = query
        disambiguations = {}
        
        context_text = " ".join([a.content for a in context])
        
        for term, meanings in self.ambiguous_terms.items():
            if term.lower() in query.lower():
                # 选择与语境最相关的意义
                best_meaning = self._select_most_relevant_meaning(
                    meanings,
                    context_text
                )
                disambiguations[term] = best_meaning
                # 不替换原文，只记录消歧结果
        
        return disambiguated, disambiguations
    
    def _select_most_relevant_meaning(
        self,
        meanings: List[str],
        context_text: str
    ) -> str:
        """选择最相关的意义"""
        # 简化实现：选择与上下文共享最多词的意义
        context_words = set(context_text.lower().split())
        
        best_meaning = meanings[0]
        best_score = 0
        
        for meaning in meanings:
            meaning_words = set(meaning.lower().split())
            score = len(context_words & meaning_words)
            if score > best_score:
                best_score = score
                best_meaning = meaning
        
        return best_meaning
    
    def _resolve_references(
        self,
        query: str,
        context: List[ContextualAssumption],
        dialogue_history: List[str]
    ) -> Tuple[str, Dict[str, str]]:
        """指称赋值"""
        resolved = query
        references = {}
        
        # 检查代词
        for pronoun in self.pronoun_rules:
            if pronoun in query:
                # 从对话历史中查找指称对象
                referent = self._find_referent(
                    pronoun,
                    dialogue_history,
                    context
                )
                if referent:
                    references[pronoun] = referent
        
        return resolved, references
    
    def _find_referent(
        self,
        pronoun: str,
        dialogue_history: List[str],
        context: List[ContextualAssumption]
    ) -> Optional[str]:
        """查找代词的指称对象"""
        # 简化实现：从对话历史中查找名词
        for utterance in reversed(dialogue_history):
            # 提取名词短语（简化）
            words = utterance.split()
            for word in words:
                if len(word) > 1 and word[0].isupper():
                    return word
        
        return None
    
    def _enrich(
        self,
        query: str,
        context: List[ContextualAssumption]
    ) -> str:
        """充实查询"""
        enriched = query
        
        # 补充省略的成分
        enrichments = []
        
        # 检测需要充实的模式
        if "怎么" in query and "用" not in query:
            enrichments.append("[使用某种方法/工具]")
        
        if "为什么" in query:
            enrichments.append("[原因/解释]")
        
        if enrichments:
            enriched = f"{query} {' '.join(enrichments)}"
        
        return enriched
    
    def _compose_explicature(
        self,
        original: str,
        disambiguated: str,
        references: Dict[str, str],
        enriched: str
    ) -> str:
        """组合完整显义"""
        parts = [f"原始查询：{original}"]
        
        if references:
            ref_str = ", ".join([f"{k}={v}" for k, v in references.items()])
            parts.append(f"指称赋值：{ref_str}")
        
        parts.append(f"充实后：{enriched}")
        
        return " | ".join(parts)


# 演示
def demo_explicature():
    """演示显义计算"""
    print("=" * 60)
    print("显义计算演示")
    print("=" * 60)
    
    computer = ExplicatureComputer()
    
    # 语境假设
    context = [
        ContextualAssumption(
            content="用户正在学习编程",
            assumption_type=AssumptionType.SITUATIONAL,
            accessibility=0.9,
            source="dialogue"
        ),
        ContextualAssumption(
            content="Python是流行的编程语言",
            assumption_type=AssumptionType.ENCYCLOPEDIC,
            accessibility=0.95,
            source="common_knowledge"
        )
    ]
    
    # 对话历史
    dialogue_history = [
        "我想学Python",
        "Python有哪些优点？"
    ]
    
    # 测试查询
    queries = [
        "它好学吗？",
        "怎么安装？",
        "Python和java哪个好？"
    ]
    
    for query in queries:
        print(f"\n查询: '{query}'")
        result = computer.compute(query, context, dialogue_history)
        print(f"  消歧: {result.disambiguated}")
        print(f"  指称: {result.references_resolved}")
        print(f"  充实: {result.enriched}")
        print(f"  完整显义: {result.full_explicature}")


if __name__ == "__main__":
    demo_explicature()
```

### 五、关联理论与Prompt设计

关联理论可以指导更有效的提示词设计：

```python
"""
基于关联理论的提示词设计原则

原则：
1. 最大化认知效果：提供足够的任务信息
2. 最小化加工努力：清晰简洁的表述
3. 语境对接：连接模型已知的知识
"""

RELEVANCE_GUIDED_PROMPT_TEMPLATE = """
## 任务描述
[清晰、简洁地描述任务，避免冗余信息]

## 语境假设
[提供模型可能需要的背景知识，但只包含必要的]
{context_assumptions}

## 输入
{input_content}

## 输出要求
[明确、具体的输出格式要求]
- 认知效果要求：{effect_requirements}
- 表达要求：{expression_requirements}

## 示例（可选）
[如果能显著降低加工努力，提供示例]
"""


class RelevanceGuidedPromptDesigner:
    """基于关联理论的提示词设计器"""
    
    def __init__(self):
        self.prompt_patterns = {
            "information_request": self._design_info_request_prompt,
            "task_execution": self._design_task_prompt,
            "analysis": self._design_analysis_prompt,
        }
    
    def design_prompt(
        self,
        task_type: str,
        input_content: str,
        context_assumptions: List[str],
        effect_requirements: List[str],
        expression_requirements: List[str]
    ) -> str:
        """设计提示词
        
        遵循关联理论原则：
        1. 只包含关联的信息
        2. 清晰组织以降低加工努力
        3. 明确期望的认知效果
        """
        
        designer = self.prompt_patterns.get(
            task_type, 
            self._design_generic_prompt
        )
        
        return designer(
            input_content,
            context_assumptions,
            effect_requirements,
            expression_requirements
        )
    
    def _design_info_request_prompt(
        self,
        input_content: str,
        context_assumptions: List[str],
        effect_requirements: List[str],
        expression_requirements: List[str]
    ) -> str:
        """设计信息请求类提示词"""
        
        # 只包含必要的语境假设
        relevant_context = self._filter_relevant_context(
            input_content,
            context_assumptions
        )
        
        prompt = f"""
请回答以下问题。

问题：{input_content}

背景信息：
{chr(10).join('- ' + c for c in relevant_context)}

回答要求：
- 直接回答问题的核心内容
- 提供必要的解释和例子
- 表达清晰简洁

请回答：
"""
        return prompt
    
    def _design_task_prompt(
        self,
        input_content: str,
        context_assumptions: List[str],
        effect_requirements: List[str],
        expression_requirements: List[str]
    ) -> str:
        """设计任务执行类提示词"""
        
        prompt = f"""
请执行以下任务。

任务：{input_content}

执行要求：
{chr(10).join('- ' + r for r in effect_requirements)}

输出格式：
{chr(10).join('- ' + r for r in expression_requirements)}

请执行：
"""
        return prompt
    
    def _design_analysis_prompt(
        self,
        input_content: str,
        context_assumptions: List[str],
        effect_requirements: List[str],
        expression_requirements: List[str]
    ) -> str:
        """设计分析类提示词"""
        
        prompt = f"""
请分析以下内容。

分析对象：
{input_content}

分析框架：
{chr(10).join('- ' + c for c in context_assumptions)}

分析要点：
{chr(10).join('- ' + r for r in effect_requirements)}

输出格式：
{chr(10).join('- ' + r for r in expression_requirements)}

请分析：
"""
        return prompt
    
    def _design_generic_prompt(
        self,
        input_content: str,
        context_assumptions: List[str],
        effect_requirements: List[str],
        expression_requirements: List[str]
    ) -> str:
        """设计通用提示词"""
        
        return RELEVANCE_GUIDED_PROMPT_TEMPLATE.format(
            context_assumptions="\n".join(f"- {c}" for c in context_assumptions),
            input_content=input_content,
            effect_requirements=", ".join(effect_requirements),
            expression_requirements=", ".join(expression_requirements)
        )
    
    def _filter_relevant_context(
        self,
        input_content: str,
        context_assumptions: List[str]
    ) -> List[str]:
        """过滤出相关的语境假设"""
        input_words = set(input_content.lower().split())
        
        relevant = []
        for assumption in context_assumptions:
            assumption_words = set(assumption.lower().split())
            if input_words & assumption_words:
                relevant.append(assumption)
        
        return relevant if relevant else context_assumptions[:3]
```
