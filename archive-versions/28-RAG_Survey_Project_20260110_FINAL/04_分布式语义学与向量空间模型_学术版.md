## 第一节 分布式假设

### 一、语境决定意义

**分布式假设（Distributional Hypothesis）**是分布式语义学的理论基石：

> "You shall know a word by the company it keeps." — J.R. Firth (1957)

**核心主张**：词语的意义由其在语料库中的分布模式决定。出现在相似语境中的词语具有相似的意义。

**形式化表述**：
```
sim(w₁, w₂) ∝ sim(context(w₁), context(w₂))

词语相似度与语境相似度成正比
```

### 二、语境的定义

**语境**可以有多种操作化定义：

| 语境类型 | 定义 | 示例 |
|---------|------|------|
| **词袋语境** | 同一文档中的词 | 文档级共现 |
| **窗口语境** | 固定窗口内的词 | ±5词窗口 |
| **句法语境** | 句法关系连接的词 | 依存关系 |
| **篇章语境** | 篇章结构中的邻居 | 同一段落 |

### 三、分布式语义的哲学基础

分布式假设与**后期维特根斯坦**的语言哲学呼应：

> "词语的意义就是它在语言中的使用。"

这一观点反对意义的心智主义解释，主张从语言使用中学习意义。

## 第二节 向量空间模型

### 一、词-文档矩阵

**向量空间模型（Vector Space Model, VSM）**将词语表示为高维空间中的向量。

**词-文档矩阵**：
```
        Doc1  Doc2  Doc3  ...
word1 [  3     0     1   ...]
word2 [  0     2     0   ...]
word3 [  1     1     4   ...]
...
```

**TF-IDF加权**：
```
tfidf(t, d) = tf(t, d) × log(N / df(t))

其中：
tf(t, d) = 词t在文档d中的频率
df(t) = 包含词t的文档数
N = 总文档数
```

### 二、词-词共现矩阵

**词-词矩阵**直接编码词语间的共现关系：

```
        word1  word2  word3  ...
word1 [   0     12     3   ...]
word2 [  12      0     8   ...]
word3 [   3      8     0   ...]
...
```

**PMI加权**：
```
PMI(w₁, w₂) = log(P(w₁, w₂) / (P(w₁) × P(w₂)))

正PMI (PPMI) = max(0, PMI)
```

### 三、降维技术

**SVD（奇异值分解）**用于降维和去噪：

```
M = U Σ Vᵀ

保留前k个奇异值：
M̂ = Uₖ Σₖ Vₖᵀ
```

**LSA/LSI**：基于SVD的潜在语义分析

## 第三节 神经词嵌入

### 一、Word2Vec

Mikolov等人（2013）的**Word2Vec**开创了神经词嵌入时代。

**CBOW（Continuous Bag of Words）**：
```
输入：语境词 [w₋₂, w₋₁, w₊₁, w₊₂]
输出：中心词 wₜ
目标：最大化 P(wₜ | context)
```

**Skip-gram**：
```
输入：中心词 wₜ
输出：语境词 [w₋₂, w₋₁, w₊₁, w₊₂]
目标：最大化 P(context | wₜ)
```

**负采样目标函数**：
```
L = log σ(v'ᵥₒ · vᵥᵢ) + Σₖ 𝔼[log σ(-v'ᵥₖ · vᵥᵢ)]
```

### 二、GloVe

Pennington等人（2014）的**GloVe**结合了全局统计和局部语境。

**目标函数**：
```
J = Σᵢⱼ f(Xᵢⱼ)(wᵢᵀw̃ⱼ + bᵢ + b̃ⱼ - log Xᵢⱼ)²

其中 Xᵢⱼ 是共现次数
```

### 三、FastText

Bojanowski等人（2017）的**FastText**引入子词信息：

```
词向量 = Σ 子词向量

"where" → <wh, whe, her, ere, re>
```

**优势**：
- 处理未登录词
- 捕捉形态信息

## 第四节 语境化词嵌入

### 一、从静态到动态

传统词嵌入为每个词分配**固定向量**，无法处理**多义性**。

```
"bank"的不同意义：
- "river bank" — 河岸
- "bank account" — 银行

静态嵌入：相同向量
语境化嵌入：不同向量
```

### 二、ELMo

Peters等人（2018）的**ELMo**使用双向LSTM生成语境化表示：

```
ELMo = γ Σₗ sₗ hₗ

hₗ: 第l层隐状态
sₗ: 层权重（任务特定）
γ: 缩放因子
```

### 三、BERT及后续

Devlin等人（2019）的**BERT**使用Transformer架构：

**预训练任务**：
- **MLM（Masked Language Model）**：预测被掩码的词
- **NSP（Next Sentence Prediction）**：预测句子对关系

**输出表示**：
```
每个token获得语境化向量：
h = Transformer(input_sequence)
```

**后续发展**：
- RoBERTa：更强预训练
- ALBERT：参数效率
- DeBERTa：解耦注意力

## 第五节 句子与文档嵌入

### 一、句子嵌入方法

| 方法 | 原理 | 特点 |
|------|------|------|
| 词向量平均 | Σ wᵢ / n | 简单但忽略顺序 |
| SIF | 加权平均+主成分移除 | 去除共同成分 |
| Sentence-BERT | 对比学习微调 | 语义相似度优化 |
| SimCSE | 对比学习+Dropout | 无监督SOTA |

### 二、文档嵌入

**Doc2Vec**（Paragraph Vectors）：
```
扩展Word2Vec，添加文档ID向量
```

**长文档嵌入挑战**：
- 位置信息丢失
- 主题漂移
- 计算成本

### 三、MTEB基准

**MTEB（Massive Text Embedding Benchmark）**是当前嵌入评估标准：

| 任务类别 | 任务数 | 评估内容 |
|---------|--------|----------|
| 检索 | 15 | 文档检索能力 |
| 聚类 | 11 | 语义聚类 |
| 分类 | 12 | 文本分类 |
| 相似度 | 10 | 语义相似度 |
| 重排序 | 4 | 候选重排 |

## 第六节 分布式语义在RAG中的应用

### 一、检索阶段的嵌入

```python
def embedding_based_retrieval(query, corpus):
    """基于嵌入的检索"""
    
    # 查询编码
    query_embedding = encoder.encode(query)
    
    # 文档编码（预计算）
    doc_embeddings = [encoder.encode(doc) for doc in corpus]
    
    # 相似度计算
    similarities = cosine_similarity(query_embedding, doc_embeddings)
    
    # 返回top-k
    return top_k(corpus, similarities, k=10)
```

### 二、语境化嵌入的优势

| 场景 | 静态嵌入问题 | 语境化嵌入优势 |
|------|------------|---------------|
| 多义词 | 混淆不同意义 | 根据语境区分 |
| 隐喻 | 字面意义主导 | 捕捉比喻用法 |
| 专业术语 | 通用意义 | 领域适应 |

### 三、Late Chunking与语境保留

```python
def late_chunking_embedding(document, encoder):
    """Late Chunking保留语境"""
    
    # 整体编码
    full_embeddings = encoder.encode_full(document)
    
    # 分块（在编码后）
    chunks = split_into_chunks(document)
    chunk_embeddings = extract_chunk_embeddings(full_embeddings, chunks)
    
    # 每个块保留全文语境
    return chunk_embeddings
```
